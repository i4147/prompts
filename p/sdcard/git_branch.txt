Write a Python command-line script that replicates the argument-parsing behavior of the `git branch`
subcommand using the `docopt` library.
The script must: - Define a module-level docstring that serves as the usage/help specification for
`docopt`, following standard docopt syntax conventions (usage patterns and options sections). -
Document the following usage patterns in the docstring:
- `git branch [options] [-r | -a] [--merged=<commit> | --no-merged=<commit>]` -
`git branch [options] [-l] [-f] <branchname> [<start-point>]` -
`git branch [options] [-r] (-d | -D) <branchname>` -
`git branch [options] (-m | -M) [<oldbranch>] <newbranch>` - Include a "Generic options" section in
the docstring listing these options with their short/long forms and descriptions:
- `-h, --help` - `-v, --verbose` (show hash and subject, give twice for upstream branch) -
`-t, --track` (set up tracking mode, see git-pull(1)) - `--set-upstream` (change upstream info) -
`--color=<when>` (use colored output) - `-r` (act on remote-tracking branches) -
`--contains=<commit>` (print only branches that contain the commit) -
`--abbrev=<n> to display SHA-1s)
- Include a "Specific git-branch actions" section in the docstring listing these options with
  descriptions: - `-a` (list both remote-tracking and local branches)
- `-d` (delete fully merged branch) - `-D` (delete branch, even if not merged) - `-m`
  (move/rename a branch and its reflog) - `-M` (move/rename a branch, even if target exists) - `-l`
  (create the branch's reflog) - `-f, --force` (force creation when already exists) -
  `--no-merged=<commit>` (print only not merged branches) - `--merged=<commit>`
  (print only merged branches) - Import `docopt` from the `docopt` package. - In the
  `if __name__ == "__main__":` block,
  call `docopt(__doc__)` to parse `sys.argv` arguments against the docstring specification,
  and print the resulting dictionary of parsed arguments and options.
The purpose of the script is to demonstrate/test how `docopt` parses a realistic,
complex command-line interface specification (modeled on `git branch`) into a dictionary of flags,
options, and positional arguments, without implementing any actual git functionality. ---
