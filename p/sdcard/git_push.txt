Write a Python command-line script that replicates a simplified version of the `git push` command's
argument parsing using the `docopt` library.
The script must: - Define a module-level docstring that serves as the usage specification
for `docopt`.
This docstring should follow standard docopt formatting conventions, including:
- A `usage:` line describing the invocation pattern:
  `git push [options] [<repository> [<refspec>...]]` - An options section listing all supported
  flags, each with a short description, including:
  - `-h, --help` - `-v, --verbose` (be more verbose) - `-q, --quiet` (be more quiet) -
  `--repo <repository>` (repository) - `--all` (push all refs) - `--mirror` (mirror all refs) -
  `--delete` (delete refs) - `--tags` (push tags (can't be used with --all or --mirror)) -
  `-n, --dry-run` (dry run) - `--porcelain` (machine-readable output)
- `-f, --force` (force updates) - `--thin` (use thin pack) - `--receive-pack <receive-pack>`
  (receive pack program) - `--exec <receive-pack>` (receive pack program) - `-u, --set-upstream`
  (set upstream for git pull/status) - `--progress` (force progress reporting) - Import `docopt`
  from the `docopt` package. - In the `if __name__ == "__main__":` block,
  call `docopt(__doc__)` to parse the command-line arguments (from `sys.argv`) according to the
  docstring specification, and print the resulting dictionary of parsed options and arguments.
Notable behavior: - The script relies entirely on `docopt` to parse arguments based on the usage
pattern and options defined in the docstring;
there is no manual argument-parsing logic. - Running the script with `-h`
or `--help` should trigger docopt's automatic help message display (derived from the docstring)
and exit. - Invalid argument combinations
or unrecognized options should cause docopt to print the usage message and exit with an error,
since no custom validation (e.g., mutual exclusivity between `--tags` and `--all`/`--mirror`) is
implemented beyond what docopt provides by default. - The output is simply the dictionary produced
by `docopt`, printed to standard output,
mapping each option/argument name to its parsed value
(boolean for flags, string/list for value-taking options
and positional arguments like `<repository>` and `<refspec>`). ---
