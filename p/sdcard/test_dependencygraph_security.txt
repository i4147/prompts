Regression test for the pathsec sandbox bypass in
``nltk.parse.dependencygraph.DependencyGraph.load`` (CWE-22; CVE-2026-12867). ``load`` opened the
caller-supplied filename with the builtin ``open``,
which bypasses NLTK's centralized file-access sentinel (``nltk.pathsec``).
Where an application enables the sandbox as a boundary and feeds it an attacker-influenced filename,
that allowed arbitrary local files to be read
and their parsed content returned via the graph's node words. ``load`` must instead route through
``pathsec.open`` so the read honours the allowed data roots.
