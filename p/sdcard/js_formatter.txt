dependency-free JavaScript/TypeScript code formatter based on token-stream processing rather than
full AST parsing.
The module should: 1.
Import a shared `Options` type from a relative `..api` module,
and a `lex` tokenizer function from a sibling `.js_tokenizer` module.
It uses these tokens to drive formatting logic instead of parsing a full syntax tree.
