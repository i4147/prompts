Backward-compatibility shim for unpickling Version objects serialized before packaging 26.1.
Old pickles reference ``packaging._structures.InfinityType``
and ``packaging._structures.NegativeInfinityType``.
This module provides minimal stand-in classes so that ``pickle.loads()`` can resolve those
references.
The deserialized objects are not used for comparisons
— ``Version.__setstate__`` discards the stale ``_key`` cache
and recomputes it from the core version fields.
