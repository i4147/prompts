Write a simple, procedural Python diagnostic script to sanity-check an OpenCV installation
and verify that image files in the current working directory can be correctly loaded.
Requirements: 1.
Add `from __future__ import annotations` at the top of the file.
Import only the `os` module and `cv2` (OpenCV) — no other dependencies.
2. On startup, print the installed OpenCV version using `cv2.__version__`, in the exact format:
`OpenCV : <version>`.
3. List all entries in the current directory via `os.listdir(".")`.
4. Filter that list to keep only filenames ending in `.jpg` or `.png` (case-sensitive),
using `str.endswith` with a tuple of extensions.
5. For each matching image file, attempt to load it using `cv2.imread(file)`.
6. If `cv2.imread` returns `None` (load failure), print a line in the exact format:
`✗ <filename>:` 7.
If the load succeeds, print a line in the exact format:
`✓ <filename>: <shape>, <dtype>`,
where `<shape>` is the loaded image's `img.shape` and `<dtype>` is `img.dtype`.
8. Use the literal Unicode characters ✓ and ✗ exactly as specified to mark success
and failure respectively for each file.
9. The script must not accept any command-line arguments and must not open any GUI
or image display window — it should only print plain text to standard output.
10. Keep the code minimal, flat,
and procedural — no functions or classes needed
— so it works as a quick diagnostic tool confirming OpenCV is installed correctly
and can read image files present in the directory where the script is executed.
