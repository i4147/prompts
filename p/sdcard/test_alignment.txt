Regression tests for nltk.translate.Alignment.
Covers the unbounded-allocation DoS (CWE-770; CVE-2026-12837):
a tiny pair with a huge left index used to force a dense per-left-index list allocation,
because the index was ``[[] for _ in range(self._len + 1)]``.
The index is now sparse (a dict keyed by the left indices that occur).
These tests confirm the index is sparse and that the public indexing / range behaviour is preserved.
The allocation test runs in a spawned process with a hard timeout so a regression to the dense
allocation cannot OOM or hang the rest of the suite.
