and presumably returns an identifier/id used by the base class. - Include a short docstring on the
class: "This represents a RadioButton." - Use proper type hints throughout
(`Optional`, `Literal` from `typing`).

— it's meant to be used as part of a Termux:GUI Python binding library module. ---
