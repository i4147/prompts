Write a Python script that acts as a command-line text-cleaning utility for files.
It takes one or more file paths and a search string as arguments,
where the search string is always the final argument.
For each specified file, it reads the content as text (tolerating invalid or non-UTF-8 bytes),
removes every line that contains the search string,
and saves the file back in place only when something was actually removed.
Lines that do not match must be preserved in their original order.
The tool should report, for each processed file,
how many lines were removed and how many characters were eliminated.
If files are not explicitly given,
the script should fall back to processing a sensible default set of files,
such as all non-binary files discovered in the current working directory tree,
skipping binary content.
If the script is invoked without any arguments,
it should print a brief usage message showing the expected syntax and exit with a non-zero status.
Files that cannot be read should be skipped gracefully without stopping the overall run.
The work across multiple files should be parallelized to speed up processing of large sets of files,
with the results aggregated and summarized at the end.
The overall behavior must be safe, predictable, and accurate,
never altering files that contain no matching lines. ---
