Write a Python script that formats C, C++, Java,
and JavaScript/JSON source files in place using the LLVM code style via the clang-format
command-line tool.
The script should accept file paths as command-line arguments;
if none are given, it should recursively discover all supported source files
(C/C++ headers and sources, Java, JavaScript, and JSON) under the current working directory.
It should process the files concurrently for speed,
skip or silently ignore any file that fails to format without stopping the overall run,
and track the total disk space change across the directory before and after formatting.
Display a colored summary at the start showing how many files were found,
and when run on a single file, format it and exit with a non-zero status code.
When multiple files are processed,
report the net change in disk usage in a human-readable format at the end.
Keep the script compact, robust to errors,
and runnable directly as a standalone command-line utility. ---
