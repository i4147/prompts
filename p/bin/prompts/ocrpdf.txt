Write a Python script that extracts the full text content from a PDF file using optical character
recognition, so it worksages as well as native text.
The script should accept the path to a PDF file as a command-line argument
and print the combined text of all pages to standard output,
with pages kept in their original order and separated by line breaks.
Because OCR on high-resolution page renders is slow,
the script should process pages in parallel across a configurable number of worker processes
(default four), with each worker opening its own handle to the document so that the work is truly
distributed.
The OCR should be English-language, run at a print-quality resolution of about 300 DPI,
and cover the full page area.
The script should read the document's page count up front,
then distribute the pages across the workers and collect results in order,
ensuring the final output is deterministic and complete.
Make sure resources are released cleanly once processing finishes,
and ensure the script is safe to run as a standalone program on platforms that spawn new
processes. ---
