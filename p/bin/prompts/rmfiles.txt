Write a Python script that reads a plain-text list of file names from a file
(defaulting to a file named "list.txt" in the current directory,
but optionally accepting a different list file path from the command line),
and deletes the files named in that list from the current working directory.
The script should ignore blank lines and lines beginning with a comment marker.
For each entry, it must only delete files that sit directly in the current working directory;
any entry that points into a subdirectory
or elsewhere on the filesystem must be skipped with a warning written to the error stream.
For each file successfully removed, report the removal to standard output.
If a listed file does not exist,
report it as not found on the error stream and continue processing the remaining entries.
If the list file itself does not exist,
print a clear error message to the error stream and exit with a non-zero status code.
After processing, if the list file itself resides in the current working directory,
delete it as well.
The script should exit with status zero on normal completion. ---
