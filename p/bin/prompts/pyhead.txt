Write a Python script that takes a file path as a command-line argument
and prints the first 1024 characters of that file to the standard output.
The script should read the file as text using UTF-8 encoding,
tolerating any undecodable bytes by ignoring them.
If the file cannot be read as text for any reason,
the script should fall back to reading the raw bytes and printing the first 1024 bytes instead.
The script should run only when executed directly as the main program,
and it should rely solely on the file path supplied at launch, with no other inputs, prompts,
or configuration. ---
