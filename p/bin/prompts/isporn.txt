Write a Python script that scans the current working directory for image files
(JPG, JPEG, PNG, and WebP) and classifies each one using a local nudity-detection model,
reporting the result for each image.
The script should set up three output folders named "safe", "sexy",
and "porn" in the working directory if they do not already exist,
and should skip any file whose path already includes one of those category folders
or a few other reserved folder names ("nude" and "safr") so previously sorted
or excluded images are not reprocessed.
For every remaining image, the script should run the detector,
determine the most likely category and its confidence score, and print a concise,
color-highlighted status line showing the file name, the category, and the score.
The script should process the files in a simple, reliable manner,
handle the detector's output gracefully,
and run as a standalone command-line tool that requires no arguments. ---
