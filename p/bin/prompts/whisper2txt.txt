Write a Python script that converts an audio recording into a plain-text transcript using a local
speech-recognition model.
The tool should accept a single audio file path (such as an M4A recording) as a command-line
argument and print a brief usage message if the argument is missing or malformed.
Before processing, it should verify that the input file exists
and exit with a clear error message if it does not.
It should load a lightweight, general-purpose speech-to-text model, transcribe the full audio,
and save the resulting text to a UTF-8 encoded output file named "out.txt" in the current
working directory.
Provide informative progress messages to the user during model loading, processing, and saving,
and confirm the output location when finished.
For convenience, also display a preview of the transcript in the console,
truncated to roughly the first 200 characters with an ellipsis if it is longer.
The script should be runnable directly from the command line and handle errors gracefully,
returning a non-zero exit status on failure. ---
