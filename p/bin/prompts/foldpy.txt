Write a Python script that scans a directory tree for Python source files
and checks each file for syntax problems, reporting the results in a clear summary.
The script should accept a target directory (defaulting to the current directory)
and an optional flag that, when enabled,
applies a safe automatic fix or cleanup step to files that are reported as problematic,
while otherwise running in a read-only reporting mode.
Key requirements: - **Discovery**: Recursively find all `.py` files under the given root path.
Skip common non-source directories such as virtual environments, version control folders,
and build or cache directories. - **Validation**:
For each file, read it as UTF-8 text and determine its status in one of three categories:
- `ok` — the file parses and compiles cleanly with no warnings. - `warn`
— the file compiles but produces compiler warnings
(for example, invalid escape sequences or other syntax-level warnings). - `error`
— the file cannot be read, fails to parse, or fails to compile. - **Parallel processing**:
Process files concurrently across multiple CPU cores to keep runtime low on large projects,
and ensure results from all workers are collected reliably. - **Progress feedback**:
Display a live progress indicator in the terminal while files are being checked. - **Reporting**:
After the scan, print a concise summary listing counts of files per status,
and list the paths of all files with `error` or `warn` status grouped by category.
Use colored, readable terminal output where appropriate,
and return a non-zero exit code if any file has an `error` status. - **Apply mode**:
When the apply flag is passed, perform a conservative,
non-destructive remediation step on problematic files
(such as creating a backup copy before modifying anything,
and only making changes that are clearly safe).
Clearly report what was changed,
and never silently overwrite files without a backup. - **Robustness**:
Handle unreadable files, encoding problems,
and permission errors gracefully without crashing the whole run. - **Command-line interface**:
Provide a helpful `--help` message describing the target path argument and the apply option.
The script should be self-contained, well-structured,
and documented with brief docstrings explaining its purpose and usage. ---
