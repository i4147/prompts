Write a Python script that takes a single file or directory path from the command line,
resolves it to an absolute location,
and moves it into a "repos" folder located in the current user's home directory.
The destination folder should keep the original item's name.
If an item with that name already exists there,
the script should generate a unique alternative name instead of overwriting anything.
Once the move completes,
the script should print a short confirmation showing the original name
and the final name it was saved under, in the form "original_name --> final_name".
Use the helper function `unique_path` from a module named `dh` to produce non-conflicting names.
The script should run only when executed directly, not when imported. ---
