Write a Python script that exports the list of packages installed on a Debian-based system into a
structured tabular file.
The script should query the system's package manager for all installed packages and collect,
for each package, a fixed set of metadata fields:
package name, version, architecture, installation status, priority, section, installed size,
maintainer, homepage, short description, source package, essential flag, multi-arch setting, origin,
and bug-tracker URL.
It should produce two output files in a designated backup directory on the device:
one tab-separated file and one comma-separated file,
both containing a header row followed by one row per installed package, with the same data in each.
The script should create the output directory if it does not exist,
handle the case where the package query tool is unavailable
(reporting that the system is not Debian-based and exiting cleanly),
and surface any errors from the package query in a clear, user-friendly message before exiting.
Upon success, it should print a concise confirmation to the user indicating
where the files were written and how many packages were exported.
Prioritize robustness with descain tabs, commas, quotes,
or newlines so that the output files remain valid and parseable. ---
