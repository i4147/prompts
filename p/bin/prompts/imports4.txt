Write a Python script that scans a project directory
(or a single Python file given on the command line)
and produces a report of all third-party packages the code depends on,
so that a user can generate an accurate requirements list.
The tool should: - Accept a path to a project folder or file as its main input,
plus optional flags for output format (plain text list, requirements-file style, or JSON),
output destination, and options to include or exclude specific directories
and to control verbosity. - Walk the source tree,
skipping common non-source directories such as version control folders, virtual environments,
build artifacts, caches, and IDE metadata,
with the ability to override that exclusion list. - Parse each Python source file safely
(handling syntax errors gracefully by logging and continuing) to find every import statement,
including nested and conditional imports, and distinguish between top-level module names.
- Filter out standard library modules,
  and map import names to their corresponding PyPI distribution names
  where they differ (for example, an import name that does not match its package name),
  using a bundled or downloadable mapping
  where available. - Optionally look up unresolved names against the PyPI index
  or the online package registry to confirm whether they exist,
  using a local cache with a configurable time-to-live to avoid repeated network requests;
the tool must degrade gracefully
when offline. - Ignore imports that are wrapped in optional-import guards
(such as try/except ImportError blocks) when requested,
and mark them separately otherwise. - Process files concurrently where it improves speed,
and report progress only when verbose mode is enabled.
- Produce deterministic, sorted, de-duplicated output,
  optionally including version pins if the user supplies
  or the tool can resolve them from the local environment. - Exit with a clear,
  non-zero status code on fatal errors (such as an invalid path) and with zero on success,
  printing human-readable messages to standard error and results to standard output
  or the chosen file. ---
