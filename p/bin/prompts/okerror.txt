Write a Python script that scans the current working directory for Python source files
and sorts them into two folders based on whether they conform to the Black code formatter's style.
The tool should ignore itself when scanning.
For each candidate file, it should run a Black formatting check;
files that pass are moved into an "ok" folder, and files that fail are moved into an "error" folder,
creating either folder if it does not already exist.
If a file with the same name already exists at the destination,
the tool should preserve both by renaming the incoming file with an incrementing numeric suffix
before its extension.
While processing, it should print a clear progress message for each file showing the file being
checked and where it was placed,
using a check mark for passing files and a clear failure indicator for failing files.
The tool should be a standalone, runnable command-line script that requires no arguments,
and it should handle the case where Black is not installed
or fails to run gracefully with a helpful message rather than crashing. ---
