Write a Python script that takes the path to a pickle file as a command-line argument,
loads the serialized data it contains,
and converts that data into a human-readable JSON representation saved alongside the original file.
The tool should validate its input before doing any work:
it must print a brief usage message and exit with an error status when no path is given,
report a clear error and exit when the file does not exist,
and reject files that not have the expected pickle extension.
It should handle arbitrary Python objects gracefully, preserving basic data types such as strings,
numbers, booleans, and nulls, recursively converting lists, tuples, dictionaries,
and sets into JSON-compatible structures,
and falling back to a string representation for anything that cannot be represented directly.
Dictionary keys must be converted to strings.
The output should be written to a file with a `.json` extension in the same directory as the input,
formatted with indentation for readability and non-ASCII characters preserved.
The script should report success with a concise message including the output location,
and should catch and report loading or writing errors without crashing with an unhandled traceback.
Keep the implementation self-contained, using only the standard library, and make the code clean,
well-structured, and safe to run on untrusted input where practical. ---
