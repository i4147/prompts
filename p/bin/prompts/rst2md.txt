Write a Python script that converts reStructuredText (.rst) documentation files into Markdown
(.md) files.
The tool should accept one or more file paths as command-line arguments;
if no arguments are given,
it should automatically find all .rst files in the current working directory and process them.
For each input file, read its content as UTF-8 text,
convert the reStructuredText into HTML body content while suppressing noisy warnings
and reporting only genuine conversion errors (printing a clear message and stopping on failure),
then convert that HTML into Markdown.
Write the resulting Markdown to a new file that keeps the original file's name and location
but uses the .md extension, encoded as UTF-8.
After a successful conversion,
remove the original .rst file so that it is replaced by the Markdown version.
Handle the case where a single file is processed as the core workflow,
and design the behavior so it is robust, readable, and easy to run from the command line. ---
