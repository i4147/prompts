Write a Python script that batch-optimizes PDF files in the current working directory by reducing
their file size using a PDF restructuring tool.
The script should discover all PDF files in the folder it is run from,
process them concurrently with a small, fixed limit on parallel workers,
and for each file report the size before and after optimization in human-readable units.
It should only replace an original file when the optimized version is actually smaller;
otherwise it should keep the original untouched, clean up any temporary output,
and report that the original was already smaller.
For each processed file, the script should print the net savings (or indicate an increase),
and at the end provide a summary of the total space saved across all files.
If an input file is missing or an external tool fails,
the script should report a clear error message to the standard error stream
and handle the failure gracefully without corrupting the original files.
The optimization should produce a linearized, web-optimized PDF with compressed object streams.
The script should be self-contained,
use only the standard library plus any helper utilities it needs to be written from scratch,
and print concise, user-friendly progress output throughout. ---
