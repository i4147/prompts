Write a Python script that converts font files into the WOFF web font format.
The tool should accept one or more font file paths as command-line arguments;
if no arguments are given,
it should automatically find all TrueType (.ttf)
and OpenType (.otf) font files in the current working directory and convert those instead.
For each input font,
produce a WOFF version saved alongside the original with the same base name and a .woff extension.
If a file with that name already exists and is non-empty,
generate a unique alternative filename rather than overwriting it.
After a successful conversion,
print a short confirmation message with the file name and delete the original source font file.
If a conversion fails for any file,
report an error message naming that file
and continue processing the remaining files without stopping.
When a single file is provided, process it directly;
when multiple files are provided, process them in parallel to speed up batch conversion.
The script should exit with a non-zero status code when run on a single file
and handle the overall run cleanly, with all user-facing output kept concise and informative. ---
