Write a Python script that takes a raw HTML fragment saved in a local file
(such as an exported CodePen body snippet) and wraps it into a complete,
standalone HTML5 document ready for use in a browser.
The tool should accept the input file path as a required argument,
and optionally an output file path and a custom page title.
If no output path is given, it should derive a sensible output filename from the input.
If no title is provided,
it should generate a readable page title automatically from the input file's name
(replacing hyphens with spaces and capitalizing words).
The generated document should include a proper HTML5 doctype, a language attribute,
UTF-8 character encoding (configurable), a responsive viewport meta tag, the page title,
and links to an external stylesheet and an external script file,
with the original fragment placed inside the body
and the script reference placed at the end of the body so that the page loads correctly.
The script should read the input file as UTF-8 text and handle common errors gracefully:
a missing input file, or any other read failure, should print a clear,
user-friendly error message to the console and exit without crashing
or producing a partial output file.
On success, it should write the complete HTML to the output file
and print a brief confirmation message indicating where the file was saved.
The tool should be runnable from the command line,
print usage help when arguments are missing or invalid,
and return an appropriate exit status (zero on success, non-zero on failure).
Keep the implementation clean, modular, and well-documented with docstrings,
and make the core HTML-wrapping logic reusable as a standalone function that other Python code can
import. ---
