Write a Python command-line tool that batch-renames files and folders in a file system,
based on a set of rename rules supplied by the user.
The tool should accept one or more file or directory paths as input,
optionally traverse directories recursively,
and filter the targets by file extension (case-insensitive)
and optionally include directories as rename candidates.
It should skip symbolic links and avoid processing the same path twice.
The core behavior is to compute new names from the original names using pattern-based
transformations such as text replacement, regular-expression substitution, prefixing, suffixing,
numbering with configurable start and padding, and case conversion.
Users should be able to combine these operations and preview the results before anything changes.
Include a dry-run mode that prints a clear before-and-after report without modifying the file
system, and an apply mode that performs the renames.
The tool must detect and refuse conflicts such as two sources mapping to the same target,
a target that already exists, or invalid characters for the operating system,
and it should report these clearly rather than overwriting data.
Support an optional undo or rollback log that records each rename so the operation can be reversed.
Process large batches efficiently, optionally using parallel workers for computing new names.
Report progress and summary statistics (counts of renamed, skipped, and failed items) through
logging, and return a non-zero exit status when errors occur.
Provide a clear help message describing all options,
with sensible defaults and validation of user-supplied arguments. ---
