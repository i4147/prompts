Write a Python script that scans a directory for Lua source files,
checks each file for syntax errors using a Lua-aware parser,
and quarantines any file that fails validation.
The tool should operate on the current working directory by default
and examine every Lua file it finds there.
For each file, it should read the source, parse it with a Lua grammar,
and walk the resulting syntax tree to detect any malformed or missing constructs.
Files that parse cleanly should be left untouched.
Files containing syntax errors should be moved into a dedicated subfolder named "error" created
alongside them, so that the original folder structure is preserved without overwriting anything.
If a file with the same name already exists in that subfolder,
the tool should rename the incoming file with a numeric suffix rather than replacing the
existing one.
Every move should be reported to the user with a clear message showing the original
and new locations.
The script should be runnable from the command line, handle missing or unreadable files gracefully,
and produce a concise summary of how many files were checked, how many were valid,
and how many were moved. ---
