Write a Python script that takes exactly two command-line arguments:
the path to a text file and a prefix string.
It should verify that the provided path refers to an existing regular file,
and if the arguments are missing or incorrect,
print a brief usage message to the error output and exit with a non-zero status.
When valid, the script should prepend the given prefix, followed by a single space,
to every non-blank line of the file while leaving empty or whitespace-only lines unchanged,
preserving the original line endings.
The modified content should be written back to the same file in place.
On success, print a short confirmation message naming the updated file to standard output. ---
