Write a Python script that converts dates between the Persian (Solar Hijri) calendar
and the Gregorian calendar.
The tool should accept a Persian date consisting of a year, month, and day,
and produce the equivalent Gregorian date,
and it should also support the reverse conversion from a Gregorian date to a Persian date.
It must validate inputs so that month values are restricted to the twelve Persian months,
and day values respect each month's length,
with the final month adjusting correctly in leap years according to the standard 33-year arithmetic
cycle rule.
When invalid input is provided, the tool should report a clear,
descriptive error message rather than failing silently or incorrect date.
The Persian month names should be available in both their transliterated English form
and their numeric position,
and the output should be presented in a readable format that shows both the numeric
and month-name representations.
The tool should be usable interactively from the command line,
accepting dates from the user and displaying results,
and it should also be structured so its conversion logic can be reused by other Python code.
Include a way to determine whether a given Persian year is a leap year.
Handle the full range of practical dates accurately, including the boundary between calendar years,
and ensure round-trip consistency so that converting a date from one calendar to the other
and back returns the original date. ---
