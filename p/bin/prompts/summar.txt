Write a Python script that takes a path to a plain-text file supplied as a command-line argument,
reads its contents as UTF-8,
and produces an extractive summary that retains roughly 70% of the original text's content using an
established text-summarization approach based on sentence ranking.
The script should save the summary to a new file placed in the same directory as the input,
with the original file name plus a "_summary" suffix before the extension, encoded as UTF-8.
It should also print the generated summary to the console.
Handle surrounding whitespace in the provided file path gracefully, and make the code clean,
readable, and robust to typical edge cases such as missing arguments, nonexistent files,
or empty input text, reporting clear error messages to the user when something goes wrong. ---
