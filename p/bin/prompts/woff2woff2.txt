Write a Python script that converts font files to the WOFF2 web font format.
The tool should accept one or more font file paths as command-line arguments;
if no arguments are given,
it should scan the current working directory for WOFF font files and process those instead.
For each input file,
produce a WOFF2 version alongside it with the same base name and a .woff2 extension.
If a WOFF2 file with that name already exists and is non-empty, do not overwrite it;
instead, gener print a confirmation message with the file name and remove the original source file.
If conversion fails for a file,
report an error message naming that file and leave the original untouched.
When multiple files are given, process them in parallel to speed up batch conversion.
When exactly one file is given,
process it directly and exit with a non-zero status code to signal completion.
Use a clean command-line entry point that returns an exit status on completion.
