Write a Python script that takes a single text file path as its command-line argument,
reads the file as UTF-8 text,
and filters its lines to keep only non-blank lines that reference video links in MKV
or MP4 format at a particular resolution.
The script should prefer the 480p resolution:
if the text contains "480" anywhere, keep only lines matching 480; otherwise fall back to 720.
Save the retained lines back to the same file, one per line,
overwriting the original content in UTF-8.
When finished, print a short summary message stating how many matching links were found. ---
