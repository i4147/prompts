Write a Python script that batch-compresses PDF files in a folder using Ghostscript to reduce their
file sizes.
The tool should accept a directory (or a set of PDF paths) as input, locate all PDF files within it,
and process them concurrently using a small,
bounded pool of worker threads so that several files are compressed in parallel without overwhelming
the system.
For each PDF, the script should produce a downsampled,
web/screen-optimized copy with the following behaviors:
- Recolor images to the sRGB color space and downsample color, grayscale,
and monochrome images to a moderate resolution (around 85 DPI) using bicubic resampling. - Target a
PDF 1.4 compatibility level, subset embedded fonts, and optimize the output file,
while not forcing all fonts to be embedded. - Write the compressed result to a temporary file
alongside the original, so the source is never corrupted during processing.
The script should report progress to the user in the console,
printing for each file the size before compression and the size after compression,
using human-readable units (KB, MB, etc.).
It should also display the Ghostscript output so the user can see its progress or errors.
After a successful run,
the script should compare the original and compressed sizes
and only replace the original file with the compressed version if the result is actually smaller;
otherwise it should discard the temporary output and keep the original.
Any temporary files must be cleaned up whether processing succeeds or fails,
and a failure on one file should not stop the others from being processed.
At the end, the script should print a summary showing the total number of files processed,
how many were reduced, and the overall space saved.
It should accept its input location from the command line,
print a usage message if arguments are missing or invalid, and exit with a clear error code on fatal
problems such as a missing Ghostscript installation or an invalid input path.
