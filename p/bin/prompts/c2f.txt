Write a Python script that runs from the command line
and converts a temperature given in degrees Celsius to degrees Fahrenheit.
The script should accept a single integer argument representing the Celsius value,
perform the standard Celsius-to-Fahrenheit conversion,
and print the result to standard output as a number rounded to two decimal places.
It should be executable directly as a program,
with the conversion logic only running when the script is launched as the main program rather than
when imported.
Keep the script minimal and focused on this single conversion task. ---
