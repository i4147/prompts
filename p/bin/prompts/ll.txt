Write a Python script that acts as a command-line directory size and listing utility.
It should accept an optional flag that reverses the sort order of the results,
and it should be runnable directly from the terminal.
The tool should take one or more file
or directory paths (defaulting to the current directory when none are given)
and report the size of each entry in a human-readable form,
using binary units (B, K, M, G, T) with the value truncated to a whole number.
A zero-byte item should display as "0 B".
For directories, the reported size should be the total of all regular files contained within them,
computed recursively,
while skipping symbolic links and any entries that cannot be accessed or no longer exist.
Missing paths or unreadable items should be handled gracefully without crashing the program.
The output should list each entry alongside its formatted size,
with the list sorted by size in ascending order by default,
and in descending order when the reverse flag is supplied.
The script should keep its output clean and readable,
and it should handle permission errors and other filesystem issues with a clear,
non-fatal message for the affected item while continuing to process the remaining entries. ---
