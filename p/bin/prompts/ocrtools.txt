Write a Python script that acts as a bat-preprocessing and OCR-evaluation tool.
It should take a folder of scanned or photographed document images and, for each image,
apply a configurable set of enhancement techniques
(such as grayscale conversion, contrast and sharpness adjustment, denoising,
adaptive or global thresholding, deskewing, and resizing).
The tool should run many combinations of these preprocessing settings in parallel across available
CPU cores, using whichever imaging libraries are installed and gracefully degrading
when optional dependencies are missing.
For each image and each preprocessing combination,
the script should run optical character recognition,
measure the quality of the extracted text
(for example by comparing against a reference transcript when one is provided,
or by using confidence scores and text statistics otherwise), and recording information.
The inputs should be a source directory of images, optional reference text files,
and command-line options to choose which techniques to test, how many workers to use,
and where to write results.
The outputs should be a machine-readable results file (such as CSV or JSON) summarizing every trial
with its settings, scores, and runtime,
plus a concise summary identifying the best-performing preprocessing combination overall
and per image.
The script should validate its inputs, report progress while running,
handle errors per file without stopping the whole batch,
and produce a clear console report at the end. ---
