Write a Python script that extracts text from PDF files in parallel,
supporting selectable extraction backends, page-range selection, and configurable output.
The tool should accept one or more PDF file paths (or a directory of PDFs)
and a set of options from the command line, including the choice of extraction engine,
an optional page range (for example, specific pages or a start-to-end range),
whether to preserve reading order, and the desired output destination.
It should process multiple PDFs concurrently,
choosing an appropriate concurrency model so that CPU-heavy parsing can run across multiple cores
while I/O-bound work stays efficient.
Each page should be extracted independently so that a failure on one page
or in one file is reported to standard error without halting the rest of the job;
the program should continue and still produce output for all successfully processed content.
The output should be plain text with clear per-page markers
(page numbers, and file names when multiple PDFs are processed),
written either to standard output or to a specified file,
with an option to write one output file per input PDF.
Pages with no extractable text should yield empty content rather than errors.
The script should validate inputs up front, give helpful messages for missing files,
invalid page ranges, or unavailable extraction engines,
and return a meaningful exit status indicating success, partial failure, or fatal error.
Include a concise help message describing all options,
and design the command-line interface so that it is easy to extend with additional extraction
backends in the future. ---
