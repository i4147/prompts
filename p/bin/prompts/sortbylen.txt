Write a Python script that acts as a command-line tool for sorting the lines of a text file by their
length, in place.
The tool should accept a file path as a required argument
and an optional flag that reverses the sort order,
so that the longest lines come first instead of the shortest.
If the path is missing,
it should print a short usage message explaining the expected command format
and exit with a non-zero status.
When the file is processed,
its lines should be reordered by length while preserving each line's original content
and line endings, and the file should be overwritten with the sorted result using UTF-8 encoding.
After saving, the tool should print a brief confirmation that includes the file name
and whether reverse ordering was applied.
Handle the input as line-based text,
keep the script self-contained and easy to run from the terminal,
and assume the target file exists and is readable. ---
