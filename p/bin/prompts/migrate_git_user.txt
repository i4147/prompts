Write a Python script that acts as a developer-machine identity migration tool:
it switches a user's local Git and SSH identity from an old username and email to a new one,
and then rewrites references to the old identity across the user's project files.
The tool should operate on the current user's home directory and must treat the old
and new identity values as configurable constants defined at the top of the script.
Its high-level behavior should cover the following: 1.
Update the global Git configuration so the user name and email point to the new identity.
2. Manage the user's SSH setup:
detect the existing key location in the standard SSH directory for a named ed25519 key,
remove or retire the old key material associated with the previous identity,
and generate a fresh ed25519 key pair for the new email address,
with appropriate handling if a key already exists
(for example, prompting or backing up before overwriting).
Ensure the SSH directory and key files get the correct permissions.
3. Scan the user's home directory recursively for common configuration
and metadata files (such as package manifests, Python packaging configs, INI/TOML/YAML files,
Markdown and plain-text files) while skipping dependency, virtual environment, cache,
and version-control directories.
Replace every occurrence of the old username and old email in those files with the new values,
and report which files were changed and how many replacements were made in each.
4. Be robust and safe:
handle missing files, permission errors, and failed subprocess commands gracefully;
log each step clearly to the console; avoid modifying files it should not touch;
and make the destructive steps (deleting keys, rewriting files) clearly announced so the user
understands what happened.
5. Run as a single command-line script with no required interactive setup beyond any confirmations
needed for destructive actions,
and finish with a concise summary of all changes made and any steps that failed
or need manual follow-up (such as adding the new public key to a Git hosting service). ---
