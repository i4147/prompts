Write a Python script that scans a directory tree and reports
which third-party packages are imported by the Python source files within it.
The tool should accept a root directory path as its input
(defaulting to the current working directory when none is given)
and recursively locate Python files,
including files with a ".py" extension as well as extensionless executable scripts
whose first line identifies them as Python.
For each Python file found, the script should parse its source safely,
skipping files that cannot be read or contain syntax errors without crashing.
It should collect the top-level names of all imported modules,
covering both plain import statements and from-import statements that refer to absolute modules,
while ignoring relative imports.
The script should aggregate these results across the entire project and produce a clear,
deduplicated, alphabetically sorted list of the imported top-level package names as its output,
printed to the console.
It should also be able to distinguish between standard library modules
and external dependencies so the user can see which packages would need to be installed,
and it should handle missing or invalid paths gracefully with a helpful message.
Keep the command-line interface simple,
and ensure the program exits cleanly with an appropriate status code on success or failure. ---
