Write a Python script that acts as a command-line utility for extracting a contiguous range of lines
from a text file and saving them to a new file.
The tool should accept three arguments:
the path to a source file, a starting line number (1-based), and an optional ending line number.
If the end line is omitted,
the extraction should run from the start line through the last line of the file.
Key requirements: - **Input validation:** Show a brief usage message to standard error
and exit with a non-zero status if required arguments are missing.
Verify that the start and end values are valid integers, that the start line is at least 1,
and that the end line (when provided) is not less than the start line.
Report clear error messages for each invalid case. - **File handling:** Confirm that the specified
source file exists before attempting to read it.
If it does not, report an error and exit with a non-zero status.
Read the source file as UTF-8 text, tolerating malformed bytes without crashing.
- **Output naming:** Automatically generate the output filename from the requested line range
  while preserving the original file's extension.
When only a start line is given, the name should reflect just that line number;
when a range is given, the name should reflect both the start and end numbers.
Write the output file in the current working directory. - **Extraction behavior:** Copy only the
lines within the requested range, inclusive of both endpoints, into the output file.
Handle cases where the requested range extends beyond the end of the file gracefully,
and make sure the output reflects only the lines that actually exist. - **Error handling:** Catch
and report file system or encoding errors during reading
or writing with informative messages on standard error, returning a non-zero exit code on failure.
On success, exit with status zero. - **Entry point:** Structure the script so it runs as a
standalone program from the command line and returns an integer exit status to the operating system.
The deliverable is a single, self-contained,
readable Python script that follows these behaviors
and produces the extracted output file exactly as described. ---
