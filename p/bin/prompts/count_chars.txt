Write a Python script that takes a single file path from the command line,
reads the file's contents as UTF-8 text, and reports the total number of characters it contains.
The script should print a clear message that includes the file name and the character count.
If the user does not supply exactly one argument,
the script should print a brief usage message showing how to run it and exit with a non-zero status.
If the specified file does not exist, the script should print a clear,
user-friendly error message naming the missing file and exit with a non-zero status.
The script should run only when executed directly, not when imported as a module. ---
