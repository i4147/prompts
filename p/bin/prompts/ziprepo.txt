Write a Python script that downloads a GitHub repository as a ZIP archive for a specified user,
repository, and branch, and saves it locally.
The tool should be run from the command line and accept the repository owner, repository name,
and an optional branch name (defaulting to the main branch),
along with an optional custom output filename.
It should authenticate to the GitHub API using a personal access token read from environment
variables, which may also be loaded from a dotenv file in the user's home directory if present.
If the token is missing,
the script should stop with a clear error message and not attempt any network requests.
The script should connect to the specified repository,
retrieve the repository archive for the requested branch,
and report progress to the user as it runs, including the repository being accessed,
the branch being fetched, and the approximate download size in megabytes.
It should write the archive to disk under a sensible default filename derived from the repository
and branch, or the user-provided name if given,
and confirm the final saved location and file size on completion.
Error handling should be robust:
if the repository or branch does not exist, if access is denied,
or if any other GitHub API error occurs, the script should report a concise,
user-friendly message rather than crashing with a raw traceback,
and exit with a non-zero status code.
Logging and console output should be clear and use simple status indicators,
and the script should be structured as a reusable command-line utility with a main entry point. ---
