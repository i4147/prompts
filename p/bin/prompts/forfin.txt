Write a Python script that acts as a batch-processing command-line wrapper around an external
command-line tool.
The script should take a file extension, the name of an external CLI application,
and any additional arguments for that application from the command line.
It should validate that the extension begins with a dot,
then scan the current working directory (non-recursively) for all files matching that extension
and run the external tool once per file,
passing along the user-supplied extra arguments followed by the path of each file.
Key behaviors to implement:
- Print a clear usage message with examples and exit with a non-zero status
when required arguments are missing. - Reject an extension that does not start with a dot,
printing a helpful error
and exiting with a non-zero status. - Process files in parallel using a pool of worker processes
sized to the number of available CPU cores,
so that many files are handled concurrently. - For each file,
report the outcome with a clear status line:
a success indicator and the file name when the tool succeeds, or a failure indicator, the file name,
and the tool's error output when it fails.
Any unexpected exception during processing of a single file should be caught
and reported without stopping the batch. - Capture the external tool's output rather than letting it
flood the console, and treat the tool's exit code as the success signal. - If no matching files are
found, inform the user
and exit gracefully. - Print a summary at the end showing how many files were processed successfully
and how many failed. - Run the main logic only when the script is executed directly.
Inputs: the file extension, the external application name,
and optional pass-through arguments supplied on the command line.
Outputs: per-file status messages and a final summary printed to the console,
with the external tool performing the actual file transformations in place
or as configured by the passed arguments. ---
