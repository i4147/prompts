Write a Python script that scans a local project or directory tree
and produces a structured summary report of its text-based source and configuration files.
The tool should be a command-line utility that accepts a root directory path as its primary input,
along with optional filters for file types, directories to skip, and a maximum file size,
all with sensible defaults built in.
When run, the script should walk the directory tree recursively,
skipping common non-source folders such as version control metadata, dependency caches,
virtual environments, and build output by default.
It should only consider files whose extensions match a curated set of text- code in many languages,
markup, data, configuration, and documentation files),
and it should ignore files that exceed a configurable size limit or appear to be binary.
For each qualifying file, the tool should gather useful metrics such as line count,
character or byte count, and the detected file type or language.
Processing of large numbers of files should be efficient,
and the work may be parallelized across multiple CPU cores when beneficial,
with results gathered reliably regardless of processing order.
The script should produce an aggregated report that includes overall totals,
a breakdown of file counts and sizes by extension or language, the largest files in the project,
and any files skipped along with the reason.
The output should be available in a human-readable console format by default
and optionally as machine-readable JSON written to a file or standard output.
It should handle missing paths, permission errors, and encoding problems gracefully,
reporting them without crashing, and it should exit with a clear status code that reflects success,
invalid input, or partial failures.
Include a clear help message describing all options,
and make the tool safe to run on large or unfamiliar directories without modifying any files. ---
