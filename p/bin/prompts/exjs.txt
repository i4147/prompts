Write a Python script that scans a directory of HTML files,
extracts the contents of every inline script block from each page,
and saves each script's contents as a separate standalone JavaScript file in an output folder.
The script should accept a source directory (or individual HTML file paths) from the command line,
locate all HTML files to process, parse each page robustly,
and report progress to the console with clear,
color-coded status messages indicating which files were processed,
how many script blocks were found, and which output files were created or skipped.
Each output file should receive a unique,
randomly generated name so that existing files are never overwritten;
if a generated name collides with an existing file,
the script should detect this and handle it gracefully.
The script should create the output directory if it does not already exist,
write all extracted content using UTF-8 encoding,
and cap the number of concurrently queued
or pending extraction tasks at a configurable maximum (default 16).
It should handle missing files, unreadable files, and malformed HTML without crashing,
continuing to process remaining files
and summarizing totals (files processed, scripts extracted, errors encountered) when finished.
Include a clear usage message when invoked without the required arguments,
and keep the overall design simple, readable, and dependency-light. ---
