Write a Python script that scans a specified source directory on an Android device's shared storage,
identifies the single largest regly inside that directory (ignoring subdirectories),
and copies its contents to a new file in a public downloads folder.
The destination filename should be a randomly generated lowercase alphanumeric-letter name of a
fixed short length with a video container extension.
After copying, the script should print the destination file's name along with the size of the copied
file in megabytes.
If the source directory contains no regular files,
the script should complete without creating a destination file or printing output.
The script should run as a standalone command-line program with the source
and destination locations hardcoded to the described Android paths. ---
