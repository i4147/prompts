Write a Python script that determines
and displays the public network connection details of the machine it runs on.
The tool should query a series of free public IP-geolocation services in order,
falling back to the next service automatically if one fails, times out, returns an error,
or provides an unusable response.
From whichever service succeeds, it should extract and present the public IP address, country,
region, city, and internet service provider (ISP) name,
handling missing fields gracefully so the output never crashes on partial data.
If every service fails, the script should report a clear,
user-friendly error message and exit with a non-zero status code.
Requirements: - Run as a standalone command-line tool with no required arguments. - Use short
network timeouts so the script never hangs for long,
and treat each service's response format as potentially different from the others. - Print the
results in a clean, human-readable layout with one labeled field per line;
optionally support a machine-readable JSON output mode selected via a command-line flag. - Show
which service provided the data so the user knows the source. - Handle keyboard interruption
(Ctrl+C) gracefully without printing a stack trace. - Include brief usage help available via a
standard help flag. - Keep the script self-contained, readable, and robust against network errors,
malformed responses, and unexpected JSON structures. ---
