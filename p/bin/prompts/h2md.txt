Write a Python script that converts HTML files into Markdown files.
The script should accept one or more file paths and/or directory paths as command-line arguments.
When a file path is given, it should be processed directly;
when a directory path is given, it should discover all HTML files within that directory.
If no arguments are provided, it should process all HTML files in the current working directory.
Each HTML file should be read as UTF-8 text, converted into Markdown,
and saved alongside the original file with the same base name and a `.md` extension.
The conversion of multiple files should be performed in parallel to speed up batch processing.
Ensure that the script handles the case where the Markdown output is not properly assigned
or written, producing a correct Markdown file for every input.
Keep the script simple, robust, and focused on this single purpose,
and include clear error handling so that a failure on one file does not stop the processing of the
others. ---
