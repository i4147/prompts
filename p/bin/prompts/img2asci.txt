Write a Python script that renders images as colored ASCII art directly in the terminal.
The tool should accept one or more image file paths as command-line arguments;
if no arguments are given,
it should automatically discover supported image files (JPG, PNG, BMP, WEBP) in the current working
directory and render those instead.
Each image should be converted to ASCII art sized to fit the current terminal width,
with the aspect ratio compensated so the output does not look stretched
(characters are typically taller than they are wide).
The output should be in full color, not monochrome.
When a single image is provided, process it directly and exit cleanly with a success status.
When multiple images are provided,
process them concurrently using a pool of worker processes (around eight),
so that the rendering of several images overlaps in time,
and wait for all of them to finish before exiting.
The script should be robust to a missing
or invalid file path by reporting a clear error for that file rather than crashing the entire run,
and it should exit with an appropriate status code when the program completes.
Keep the overall design simple and readable,
with a clear entry point guarded so the script can also be imported without side effects. ---
