Write a Python script that scans a project directory recursively for Python source files
and produces a summary of all the import statements they contain, organized by folder.
The script should skip hidden directories,
virtual environment or package directories (such as site-packages),
and any previously generated output folder,
so that only the project's own source files are analyzed.
For each qualifying file,
the script should parse the source code using a proper syntax-aware parser rather than simple text
matching, and extract only the top-level import statements
(both plain imports and "from ... import ..." forms), preserving their exact original text.
Files that cannot be read or parsed should be handled gracefully without stopping the overall run.
The results should be grouped by folder,
with each folder's collected imports listed alongside the file they came from,
and displayed or saved in a clear, human-readable report.
Paths in the report should be shown relative to the project root where possible,
falling back to the original path otherwise.
The script should also track
and report summary statistics such as the total number of files processed
and the number of distinct folders discovered.
The output should be written to an output directory created automatically in the working location if
it does not already exist,
and the script should run as a standalone command-line tool with no required user input. ---
