Write a Python script that scans the current working directory for image files (JPEG, PNG, and WebP)
and automatically detects images containing nudity,
moving each flagged image into a dedicated subfolder named "nude" so it can be reviewed
or separated from the rest.
The script should: - Accept an optional command-line flag that enables downscaling of large images
(larger than 800 pixels in either dimension) before analysis to speed up detection,
while leaving smaller images untouched.
Without the flag, analyze images at their original size. - Process images concurrently across
multiple files to make batch scanning efficient. - Skip any files that already reside inside the
"nude" folder so that previously moved images are not reprocessed. - Create the "nude" folder in the
working directory if it does not already exist. - For each image,
print the filename as progress feedback and print the detection result details for transparency. -
When an image is classified as nude,
print a highlighted notification with its filename and move the file into the "nude" folder,
preserving its original name. - Handle images that cannot be read or analyzed gracefully,
so that a single failing file does not stop the overall batch. - Operate only on the files in the
current directory tree and make no network requests or external API calls. ---
