Write a Python script that extracts Python code blocks from Markdown files
and saves each one as a separate standalone Python file.
The tool should accept zero or more Markdown file paths as command-line arguments.
If no paths are given,
it should automatically process all Markdown files in the current working directory,
in a consistent sorted order.
For each path, it should skip anything that is not a regular file and report that it was skipped.
For every file processed,
the tool should locate all fenced code blocks explicitly tagged as Python
(using common tags such as "python" or "py"), ignoring blocks in other languages.
Each matched block's content should be captured exactly as written,
preserving indentation and line breaks.
Each extracted block should be written to the current working directory as its own file,
named with a zero-padded sequential number (for example, ex01.py, ex02.py, and so on),
numbered globally across all processed Markdown files in the order encountered.
The files should be saved using UTF-8 encoding.
As progress output, the tool should print one line per extracted block showing the source Markdown
filename and the newly created output filename.
After processing everything,
it should print a closing summary stating the total number of Python code blocks extracted.
The script should be runnable directly from the command line
and should not require any external dependencies beyond the Python standard library. ---
