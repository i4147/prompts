Write a Python script that scans a directory tree recursively,
starting from the current working directory by default
(with the option to specify a different root directory),
and identifies the 10 largest regular files by size in bytes.
The script should handle large directory trees efficiently without storing every file in memory,
skip entries that are not regular files,
and gracefully ignore files that cannot be accessed due to permission or other OS-level errors.
When finished, it should output the results sorted from largest to smallest,
with each line showing the file size in bytes followed by the file's path,
and it should run this report when executed directly from the command line. ---
