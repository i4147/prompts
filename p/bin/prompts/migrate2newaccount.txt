Write a Python script that migrates a collection of local Git repositories to a new GitHub account.
The script should run from a parent directory containing multiple project folders,
skip a configurable set of excluded folder names
(such as large upstream source trees and version-control metadata directories),
and process each remaining subdirectory that is an initialized Git repository.
For each eligible repository, the script should:
- Stage all current changes
and create a single sync commit only if there are uncommitted modifications. - Create a private
repository under the target GitHub account with the same name as the local folder,
using the GitHub command-line tool. - Repoint the repository's origin remote to the new account's
SSH address. - Push all local branches and all tags to the new origin, setting upstream tracking.
The script should handle errors gracefully so that a failure in one repository
(for example, a repository that already exists on GitHub or a push that is rejected) does not stop
processing of the remaining repositories.
It should return to the parent directory after each repository is handled,
skip non-Git folders without treating them as failures,
and conclude with a summary report listing which repositories were migrated successfully and
which encountered problems.
The target account name should be a single, easily changeable setting at the top of the script,
and command output should be captured so the terminal stays readable,
while still surfacing a clear log of each step's outcome. ---
