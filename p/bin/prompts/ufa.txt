Write a Python script that acts as a command-line utility for decoding Unicode escape sequences
found in text files.
When run with no arguments,
it should scan the current working directory and process all non-binary text files it finds.
When given one or more arguments, each argument may be a file path or a directory path:
individual non-binary files are processed directly,
and directories are expanded to include the non-binary files they contain.
For each non-binary file,
read its contents as UTF-8 text
and treat every non-empty line as a hexadecimal Unicode code point fragment
(for example, a value such as "1F600" or "00E9").
For each such line, output two results to standard output:
first, the original line in its escaped form, prefixed so it reads as a \u-style escape;
second, the decoded character or characters that the escape represents.
Ensure the decoding is robust to malformed input,
so that invalid entries do not crash the program and are reported clearly to the user instead.
Skip binary files entirely,
and make sure files that cannot be read are handled gracefully with a helpful message.
The script should exit cleanly with a status code of zero on success
and a non-zero status code on fatal errors.
Keep the output readable, with each original value and its decoded result easy to distinguish,
and include a brief usage message if the user requests help or supplies invalid arguments. ---
