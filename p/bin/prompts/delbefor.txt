Write a Python script that takes a text file path and a target character from the command line,
then rewrites that same file in place.
For each line, it removes surrounding whitespace and skips lines that are empty after trimming.
For lines that contain the target character,
it keeps only the portion of the line starting from the first occurrence of that character,
discarding everything before it.
Lines that do not contain the target character are kept as their trimmed form.
Blank lines are dropped entirely.
The result should be saved back to the original file as UTF-8 text,
with the remaining lines joined by newlines.
If no lines remain after processing,
the file should be left unchanged rather than being overwritten with empty content.
The script should be runnable from the command line as a standalone tool,
read the file's contents line by line,
and handle the file safely with clear behavior for missing arguments or unreadable files. ---
