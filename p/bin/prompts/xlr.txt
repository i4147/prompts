Write a Python script that takes a single text file path as a command-line argument
and rewrites that file in place so that every existing line is followed by a large block of blank
lines (three extra empty lines beyond the normal line break),
effectively spacing out the content vertically.
The script should read the file's full text, preserve the original line contents,
insert the extra blank space after each line, and save the result back to the same file.
It should run as a standalone command-line tool, expecting exactly one file argument,
and handle the file reading and writing cleanly without requiring any additional user input
or output beyond the modified file. ---
