Write a Python script that cleans up the output of a pip freeze dependency listing,
reducing each entry to just its bare package name.
The script should accept a single command-line argument giving the path to an existing text file
containing pip freeze output.
If the file does not exist,
it should exit with a clear error message rather than failing with a stack trace.
The script should read the file as text (tolerating encoding issues),
then process each line as follows:
- Ignore blank lines
and comment lines (those beginning with a hash symbol). - Skip lines that are direct VCS
or URL references (such as entries beginning with git+, http://, or https://),
since they do not map to a simple package name. - For direct references in the form "name @
location", keep only the package name before the at sign. - For standard version specifiers
(such as "name==1.2.3", "name>=2.0", or editable-install lines prefixed with "-e"),
extract only the package name portion, which may contain letters, digits, underscores, dots,
and hyphens. - Discard any line from which no valid package name can be determined.
After processing, the script should overwrite the original file so that it contains only the
extracted package names, one per line,
preserving the original order and keeping duplicates removed or retained in a consistent,
sensible way.
The script should be runnable from the command line with a short description in its help text
explaining that it cleans pip freeze output in place, keeping only package names.
Focus on producing a robust, dependency-free,
readable tool that handles edge cases in pip freeze output gracefully,
and make sure the final file ends with a trailing newline. ---
