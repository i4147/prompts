Write a Python script that summarizes a plain-text document using frequency-based extractive
summarization.
The tool should read a UTF-8 encoded text file from a path supplied on the command line,
produce a condensed summary of its content, and save the result to a text file.
If no output path is given,
the summary should be written next to the input file using a name derived from the original file
name with a "_summary" suffix.
The script should offer a command-line interface
where the user can choose the summarization approach
(at least two variants,
such as a summarization style that scores sentences by the frequency of meaningful words,
and a simpler variant that favors shorter,
direct selection) and the target language for stopword filtering, with English as the default.
It should allow the user to control the length of the summary,
either as a number of sentences or as a proportion of the original text.
Input validation should provide clear error messages for unknown variants, unsupported languages,
missing files, or empty input, and the program should exit with a non-zero status code on failure.
Core behavior: normalize and tokenize the text, remove common stopwords for the chosen language,
compute word frequencies,
score each sentence by the weight of its significant words
(optionally normalized by sentence length),
and select the highest-scoring sentences while preserving their original order in the output.
The script should also print a short preview of the generated summary to standard output so the user
can check the result immediately.
Design the tool so that the summarizer is a reusable component that can be used independently of the
command-line entry point, and make sure it handles edge cases such as very short documents,
documents with no meaningful words, and text containing unusual punctuation or whitespace. ---
