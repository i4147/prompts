Write a Python script that fetches the public repositories of a given GitHub user
and saves a human-readable summary of them to a text file.
The tool should accept a GitHub username and an optional output file path.
It should query GitHub's public API for that user's repositories and handle the case
where the user has no repositories by informing the user without creating an empty report.
For each repository, the report should include the repository name,
a description (with a fallback message when none is provided), its web URL, star count, fork count,
and primallback when unspecified).
The output should begin with a header identifying the username and a visual separator,
followed by one clearly delineated entry per repository.
Handle network failures and error responses from the API gracefully,
reporting a clear message to the user rather than crashing.
When no output file is specified,
the script should choose a sensible default filename derived from the username.
Output text should be UTF-8 encoded so that non-ASCII repository descriptions are preserved.
The script should be runnable from the command line,
taking the username (and optionally the output path) as arguments,
and should print a confirmation message with the location of the saved file upon success. ---
