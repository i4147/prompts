Write a Python script that converts font files to the WOFF2 web font format.
The tool should accept one or more font file paths as command-line arguments;
if no arguments are given,
it should automatically find all TrueType (.ttf)
and OpenType (.otf) font files in the current working directory and convert those.
For each input font, it should produce a WOFF2 file placed alongside the original,
using the same base name with a .woff2 extension.
If a WOFF2 file with that name already exists and is non-empty,
the tool should generate a unique alternative filename rather than overwriting it.
After a successful conversion, the original font file should be deleted,
and a short confirmation message naming the converted file should be printed.
If a conversion fails,
the tool should report an error for that specific file without stopping the processing of other
files, and the original file should be left untouched.
When multiple files are supplied,
they should be processed concurrently in parallel to speed up the batch.
When exactly one file is supplied, it should be processed directly,
and the script should exit with a non-zero status code after handling it.
The tool should be a simple,
dependency-light command-line utility suitable for batch font conversion in a developer's
workflow. ---
