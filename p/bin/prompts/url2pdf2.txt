Write a Python script that takes a single website URL from the command line
and saves the full rendered web page as a PDF file in the current working directory.
If the user runs the script without providing a URL,
it should print a short usage message showing the expected command format
and exit with a non-zero status code.
The script should accept URLs with
or without a scheme (for example,
both "example.com" and "https://www.example.com/page" should be valid inputs).
Before converting, normalize the input so that a missing scheme defaults to HTTP.
Name the output file automatically based on the website's host name:
remove a leading "www." prefix, replace any character that is not a letter, digit, underscore,
or hyphen with an underscore, and append the ".pdf" extension.
If the host name cannot be determined, fall back to a generic name such as "website".
Perform the conversion using a reliable HTML-to-PDF approach capable of fetching
and rendering the page at the given URL.
When the conversion succeeds, print a single confirmation line in the form "Saved: <filename>.pdf".
Handle errors gracefully:
if the URL is unreachable or the conversion fails, display a clear,
user-friendly error message
and exit with a non-zero status code rather than showing a raw stack trace.
The script should be self-contained, runnable as a standalone command-line tool,
and written with clean, readable code and sensible comments. ---
