Write a Python script that takes a file extension from the command line
and reports summary statistics for all files with that extension found recursively within the
current working directory.
The script should accept the extension with or without a leading dot,
and should print a short usage message with an example
and exit with an error status if no extension is provided.
If no matching files exist, it should inform the user and exit cleanly.
Otherwise, it should display the total number of matching files
and their combined size in a human-readable format (such as bytes, KB, MB, or GB, as appropriate).
Use the tool's standard output for all results
and ensure the script runs as a standalone command-line program. ---
