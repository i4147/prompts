Write a Python script that acts as a command-line tool for migrating Python 2 style source code
and Python 2–tagged distribution artifacts toward Python 3 compatibility.
The tool should accept one or more file or directory paths as input,
scan them recursively for Python source files (with configurable file extensions),
and apply automated source transformations to make the code compatible with Python 3.
It should support running the transformations as a dry run that reports proposed changes
(ideally as concise diffs, with a configurable limit on the amount of output shown) without
modifying files, and as a write mode that applies changes in place.
The tool should allow the user to select or exclude specific transformation rules,
and should be able to run the work in parallel across multiple worker processes with a configurable
worker count.
In addition to source files,
the tool should be able to inspect archive files
(such as zip, wheel, tar, and gzipped tar archives),
locate metadata files that declare a Python 2-only wheel tag
(for example, a WHEEL file containing a "py2-none-any" tag),
and report or rewrite those tags to Python 3 equivalents,
repacking the archive when changes are applied while preserving the original structure
and file contents otherwise.
Temporary working directories should be used safely and cleaned up afterward.
For source transformations,
the tool should also perform lightweight contextual analysis to flag
or skip risky constructs
(for example, code inside string literals or comments should not be altered),
and should emit a summary report at the end showing how many files were scanned, changed, skipped,
or failed, along with which rules were applied.
Errors on individual files must not stop the overall run; they should be logged and counted.
The tool should support configurable logging verbosity,
a clear exit status reflecting whether any failures occurred,
and optional validation that each rewritten file still parses as valid Python 3 syntax before
it is saved.
Provide sensible defaults for all options, and include a help message describing every option. ---
