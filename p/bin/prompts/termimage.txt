Write a Python script that acts as a terminal-based image viewer
and converter for a directory of image files.
The tool should accept a file or folder path from the command line,
locate supported image files
(common raster formats such as PNG, JPG/JPEG, GIF, BMP, and WebP, matched case-insensitively),
and present them in a compact, readable way that fits the current terminal width.
It should handle portable pixmap images (PPM in both binary and ASCII variants) by parsing their
headers and pixel data directly, skipping comment lines,
and converting the pixel values into a displayable form.
The script should gracefully report unsupported, corrupted, or unreadable files without crashing,
continue processing the remaining files, and print a clear summary of what was rendered or skipped.
Include sensible command-line options such as choosing a target width,
limiting the number of files shown,
and toggling a verbose mode that reveals image metadata like dimensions and maximum color value.
Output should be human-readable text rendered to the terminal,
with errors written to standard error and a non-zero exit status
when no valid images can be processed.
Keep the implementation self-contained, cross-platform,
and free of external dependencies beyond the Python standard library. ---
