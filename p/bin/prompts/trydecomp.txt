Write a Python script that acts as a universal archive and compression inspector/extractor:
given a file path to a compressed or archived file,
it automatically detects the format (from file extension and/or magic bytes),
and either lists its contents or extracts them to a target directory.
The script should: - Accept a single input file path plus optional arguments for an output directory
and a mode (list contents, extract, or detect format only), and print clear,
human-readable results to the console. - Automatically identify the container
or compression format by inspecting file signatures rather than relying solely on the extension,
and fall back to extension-based detection
when signatures are ambiguous. - Support the common formats in the standard library, including gzip,
bzip2, LZMA/XZ, zlib-wrapped data, ZIP, and TAR (including compressed TAR variants),
as well as raw single-stream compressed files that should be decompressed to a file with the
appropriate name. - Optionally support additional third-party formats
(such as Brotli, Zstandard, 7z, RAR, ISO, CAB, and LZMA-alone streams) only
when their libraries are installed,
degrading gracefully with a clear message when a required optional dependency is missing.
- Include safety protections during extraction:
  prevent path traversal ("zip slip"/"tar slip") outside the target directory,
  refuse absolute or otherwise escaping member paths,
  and avoid overwriting existing files
  unless explicitly allowed. - Report errors
  (corrupt archives, unsupported formats, missing files, permission problems) with meaningful
  messages and a non-zero exit status,
  without crashing with an unhandled traceback. - Optionally display progress
  or summary statistics such as the number of entries, total uncompressed size,
  and compression ratio
  when listing. - Be organized so new format handlers can be added easily through a registry-style
  design, and keep the core logic independent of the command-line interface so it can also be
  imported and used programmatically. - Use only the Python standard library for the required
  functionality, treating every optional third-party package as an enhancement that is safely
  skipped when absent. ---
