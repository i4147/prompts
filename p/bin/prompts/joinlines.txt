Write a Python script that takes a single file path from the command line,
reads the file as UTF-8 text, removes all blank or whitespace-only lines,
and joins the remaining lines together into one continuous string with no separators,
then overwrites the original file with that joined text followed by a single trailing newline.
The script should be runnable from the terminal with the file path as its only argument,
use UTF-8 encoding for both reading and writing, and exit cleanly upon completion. ---
