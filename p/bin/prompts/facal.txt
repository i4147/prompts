Write a Python script that prints today's date in the Persian (Jalali/Solar Hijri) calendar,
formatted for display in Persian text.
The script should take the current Gregorian date, convert it accurately to the Jalali calendar,
and output a readable Persian-language date line that includes the Persian month name,
the day and year rendered with Persian (Eastern Arabic) digits,
and the Persian weekday name for the current day.
Key behaviors: - Determine today's date automatically from the system clock;
no user input is required. - Perform an accurate Gregorian-to-Jalali conversion using a standard
algorithm, handling leap years correctly. - Map the weekday to its Persian name,
respecting that the Persian week starts on Saturday. - Render all numeric parts using Persian
digits, and use Persian month
and weekday names with correct Persian typography
(including zero-width non-joiners where appropriate in compound weekday names). - Print the result
to standard output as a single, cleanly formatted line, such as the weekday, day, month name,
and year in a natural Persian ordering. - Optionally support a short abbreviated weekday form for
compact display, selectable via a simple command-line flag. - Use a small set of helper utilities
for conversion and formatting so the logic is clear
and testable. - Handle any dependency on a Persian text-rendering or formatting helper gracefully,
so that the output displays correctly in a terminal that supports right-to-left Persian text. - The
script should run with no external setup beyond the standard Python environment
and any text-rendering helper it relies on, and should exit cleanly with status 0 on success. ---
