Write a Python script that plays an audio file from either a local file path or a web URL and waits
until playback has fully finished before returning.
The script should expose a reusable function that accepts a sound source
(a local path or an http/https link) and a blocking flag, and should raise a clear,
custom error if the audio backend fails to start playback.
Requesting non-blocking playback should be rejected with a clear error stating it is not yet
supported on this platform.
When run directly from the command line,
the script should take the sound file path or URL as its first argument and play it,
exiting cleanly once playback completes.
Focus on reliable completion detection, resource cleanup after playback,
and informative error messages for invalid input or playback failures. ---
