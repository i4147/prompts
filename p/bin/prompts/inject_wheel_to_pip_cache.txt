Write a Python script that builds and manages a local cache of Python wheel files,
keyed by source URL and the current Python interpreter's identity (implementation name and version),
so that wheels built or downloaded for one interpreter are not reused by another.
The script should accept a cache root directory
and a source URL (or local path converted to a file URL), derive a stable,
deterministic storage location within the cache from a hash of that identity,
and organize cached entries into a nested,
sharded directory structure to avoid overly large single directories.
The script should also be able to inspect a given wheel archive (a ZIP-format .whl file)
and extract its core package metadata,
specifically locating the METADATA file inside the wheel's dist-info directory,
parsing it as an email-style header block,
and returning the relevant fields (such as package name, version, and requirements) as
structured data.
If a wheel contains no metadata file or is malformed, the script should report a clear,
descriptive error rather than failing silently.
Key expectations: - Produce identical cache locations for identical URL
and interpreter combinations across runs,inct locations
when either differs. - Handle filesystem paths
and file URLs correctly across operating systems. - Provide clear error messages for missing
or invalid wheel files missing metadata. - Allow the cached results
and extracted metadata to be presented as machine-readable output (e.g., JSON) for use by other
tools. - Be safe to run repeatedly:
creating cache directories should be idempotent,
and existing cache entries should not be corrupted. - Include a simple command-line interface that
accepts the cache directory, a URL or wheel path, and an option to print metadata. ---
