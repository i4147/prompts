Write a Python script that merges multiple requirements files found in the imm a given root folder
into a single consolidated requirements file placed in that root folder.
The script should accept a root directory path as input
(defaulting to the current working directory if none is provided) and an optional flag that,
when enabled, deletes the original per-subdirectory requirements files after a successful merge.
It should scan only the first level of subdirectories under the root,
and consider a subdirectory only if it contains a file named requirements.txt.
For each discovered requirements file, process its contents in a stable,
sorted order by subdirectory name.
Before the entries from each file,
insert a clearly visible comment header identifying which subdirectory the entries came from.
Preserve blank lines and comment lines exactly as they appear in the source files.
Deduplicate package requirement lines across all files so that the first occurrence is kept as-is,
and any later repeated requirement (compared after trimming surrounding whitespace) is retained in
the output but marked as a duplicate by prefixing it with a comment that indicates it is
a duplicate.
Separate each source file's section with a blank line,
and ensure the final output ends with a single trailing newline.
If no subdirectories containing a requirements file are found,
the script should print a clear message to the user stating that no requirements file was found in
the top-level subdirectories, and it should not create or modify any output file.
Otherwise, write the merged result to the root directory's requirements.txt file,
overwriting any existing file there, and report to the user the path of the generated file.
Handle file read and write errors gracefully with informative messages rather than crashing with an
unhandled traceback.
Provide a command-line interface with clear help text describing the root directory argument
and the option to remove the original files, so the tool can be run directly from a terminal. ---
