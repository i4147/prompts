Write a Python script that displays an image in the terminal as colored block art,
taking a single image file path from the command line.
The script should load the image,
report a clear error and exit gracefully if the file does not exist,
and scale the image to a fixed display height of 100 character rows
while preserving its original aspect ratio.
Because terminal character cells are roughly twice as tall as they are wide,
the output width should be doubled relative to the scaled width so the picture does not
appear stretched.
Each pixel of the resized image should be rendered as a single space character with its background
colored using the 256-color ANSI terminal palette,
mapping RGB values to the nearest palette entry
(with a dedicated grayscale ramp for neutral tones and the 6×6×6 color cube for everything else).
Each row should be printed on its own line,
and every color block should be reset afterward so the terminal output stays clean.
The script should run as a standalone command-line tool
and produce no output beyond the rendered image. ---
