Write a Python script that scans the current working directory recursively
and removes broken symbolic links, reporting each action to the user.
The tool should skip anything located inside version-control metadata folders.
It must support a dry-run mode, activated by a command-line flag,
in which broken links are only listed and not deleted.
In normal mode, each broken link found should be deleted
and a message printed naming the file removed.
In dry-run mode, each broken link should be reported with a note that it would be removed if the
flag were omitted.
The script should run its main logic from the command line,
exit cleanly with a status code when finished, and require no third-party dependencies. ---
