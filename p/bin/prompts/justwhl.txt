Write a Python script that operates on the immediate subdirectories of the current working
directory, locating a Python wheel (.whl) package in each one and cleaning up everything else.
For each subdirectory,
the script should search for a wheel file either directly inside it
or inside a nested "dist" folder.
If a wheel is found outside the top level of the subdirectory (for example, in "dist"),
the script should move it up to the subdirectory's root.
After that, it should delete all other contents of the subdirectory,
including nested folders and files, while preserving only the kept wheel file;
symbolic links should be removed as links rather than followed.
If no wheel exists in a subdirectory,
the script should report that the folder was skipped and leave it untouched.
The script should print clear, human-readable status messages for each action taken:
moving a wheel, removing an item, completing a folder with the wheel retained, or skipping a folder.
It should handle the top-level iteration by considering only directories (not regular files) within
the current working directory,
and it should process each one independently so that an issue with one folder does not prevent the
others from being cleaned.
The goal is a simple,
safe utility for normalizing a set of build
or download folders so that each one contains exactly one wheel file at its root. ---
