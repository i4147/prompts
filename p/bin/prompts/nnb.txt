Write a Python script that operates as a command-line utility for in-place text file transformation.
The script must accept exactly one argument: the path to a text file.
If the argument count is wrong,
it should print a brief usage message showing how to invoke the script
and exit with a non-zero status code.
When given a valid file path, the script should read the file's entire contents as UTF-8 text,
convert every actual line break into a literal two-character escape sequence
(a backslash followed by the letter "n") so that the whole content ends up on a single line,
and then write the transformed text back to the same file,
overwriting the original contents with UTF-8 encoding.
No other characters should be altered, and the script should produce no output on success.
Keep the implementation simple and self-contained, using only the Python standard library,
and ensure the script runs as a standalone program when executed directly. ---
