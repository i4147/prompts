Write a Python script that runs from the command line and deletes a range of lines from a text file.
The script takes a file path as its first argument, followed by either one or two line numbers:
a start line and an optional end line.
When only a start line is given, all lines from that point to the end of the file should be removed.
When both a start and end line are given,
the lines in that inclusive range (1-based numbering) should be removed.
The file should be read as UTF-8 text, the remaining lines saved back to the same file,
and a message reporting how many lines remain should be printed to the console.
Handle the case where the arguments are missing or malformed with a clear usage message,
and make sure line numbers outside the file's bounds are handled gracefully without crashing. ---
