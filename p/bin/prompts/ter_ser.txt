Write a Python script that recursively scans a target directory
(or the current working directory when none is given) for JavaScript source files with the
extensions .js, .jsx, .jsm, and .jsc,
and minifies each one in place using the Terser command-line minifier with compression
and name mangling enabled.
The script should accept one or more file or directory paths as command-line arguments,
expanding directories into the JavaScript files they contain.
Behavior requirements:
- Skip any file already named with a ".min.js" suffix so that previously minified outputs are not
reprocessed. - Skip files located inside a notebook-related site-packages directory. - Skip files
that do not exist, are empty, or consist of only a single line,
since they are assumed to be already minified. - Invoke the external minifier safely:
if it fails, report the error message to standard error
and leave the original file untouched. - On success,
overwrite the original file with the minified output, UTF-8 encoded,
and report the size reduction (original size versus new size, and the percentage saved) for each
processed file, along with a final summary of how many files were processed
and the total bytes saved. - Handle missing arguments, invalid paths,
and missing Terser installation gracefully with clear,
user-friendly messages
and a non-zero exit code on fatal errors. - Print progress information so the user can follow
which file is being processed.
The script should be runnable from the command line,
be robust against individual file failures without aborting the whole batch, and produce a concise,
readable console report. ---
