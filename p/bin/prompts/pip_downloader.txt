Write a Python script that reads a text file containing a list of PyPI package names
(one per line, ignoring blank lines and lines beginning with a "#" comment marker),
looks up each package's metadata on the public Python Package Index,
and downloads a source distribution archive for each package into a local output folder.
The script should take the path to the package-list file as its single command-line argument
and print a usage message and exit cleanly if the argument is missing or incorrect.
For each package, the script should query the PyPI JSON metadata for the latest release,
inspect the list of available distribution files,
and prefer source archives in the order of .tar.gz, then .tar.bz2, then .zip.
Each downloaded file should be saved into a "downloads" directory created automatically if it does
not exist, using the original filename provided by the index.
The script should handle HTTP requests with redirects enabled, a reasonable timeout,
and a descriptive User-Agent header, and should reuse a single network session for all requests.
Error handling is important:
a failure for one package
(unknown package name, network error, missing source archive, or a failed download) must not stop
processing of the remaining packages.
Report each package's outcome clearly to the user in the console, such as success,
skipped because no preferred source archive exists, or the specific error encountered,
and finish with a brief summary showing how many packages were downloaded successfully
and how many failed or were skipped. ---
