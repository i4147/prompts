Write a Python script that scans the current working directory
and all of its subdirectories forwhl),
identifies which wheels contain no Python source or compiled extension content,
and moves those "empty" wheels into a single dedicated folder named "empty_wheels" created in the
working directory.
The script should treat a wheel as "empty" when its archive contains no files with Python source,
compiled extension, or Python stub extensions.
If a file is not a valid ZIP archive, the script should print a clear warning naming that file,
skip it, and not treat it as empty.
Behavior requirements:
- Search recursively from the current directory for every wheel file,
considering only actual files. - Evaluate each wheel
and collect the list of empty ones without modifying anything during evaluation. - If empty wheels
are found, print a summary line stating how many were found,
then list each wheel's path relative to the current directory,
and move each one into the "empty_wheels" folder,
creating that folder if it does not already exist. - If no empty wheels are found,
print a message stating so. - Keep output concise and user-friendly,
and make the script runnable as a standalone command-line program with a main entry point.
Focus on clean, readable, robust code that handles filesystem and archive errors gracefully. ---
