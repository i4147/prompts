Write a Python script that acts as a standalone HTML sanitizer
and syntax-highlighting preparation utility.
It should accept raw HTML content (from a string or file) and produce a cleaned,
safe version of that HTML suitable for display in a web page.
Key requirements: - **Purpose:** Parse HTML input and output a normalized, sanitized HTML string.
Remove or neutralize potentially dangerous or malformed markup
while preserving legitimate formatting and text content. - **Input:** A raw HTML string,
optionally read from a file path or standard input.
The tool should gracefully handle unclosed tags,
self-closing void elements (such as line breaks, images, and inputs),
and unescaped entities. - **Output:** A clean HTML string written to standard output
or a specified file,
with consistent structure
and properly escaped text. - **Sanitization behavior:** Strip script-like elements,
event-handler attributes, and unsafe URL schemes from links and images.
Allow a reasonable whitelist of common formatting, structural,
and media tags. - **Code block awareness:** Recognize code blocks within the HTML
and tag them with a language class
when the language is among a known list of supported highlighting languages
(covering common languages such as Python, JavaScript, C++, Ruby, Bash, SQL, XML, CSS,
and many others).
Unknown or missing languages should fall back to a plain,
safe default. - **Robustness:** Never crash on malformed input;
report problems to standard error and continue processing
where possible. - **Configurability:** Allow the caller to supply custom tag
and attribute whitelists,
and optionally toggle language tagging on
or off. - **Usability:** Provide a simple command-line interface with options for input source,
output destination, and the configuration flags above,
plus a short usage message on invalid arguments. - **Testing expectation:** Include a small set of
self-checks or example inputs demonstrating that dangerous markup is removed, void tags are handled,
and code blocks receive the correct language annotations.
Choose the implementation approach, data structures, and libraries freely, prioritizing correctness,
security, and readability. ---
