Write a Python script that backs up the installed third-party packages from the active Python
environment's site-packages directory into a persistent cloud storage location,
designed to run inside a Google Colab notebook.
The script should mount the user's Google Drive, create a destination folder if it does not exist,
and then process every top-level entry in the site-packages directory.
Standalone files should be copied as-is into the destination,
while each package directory should be compressed into a single archive file named after
the package.
When archiving, the script should include all regular files within the package
but skip compiled bytecode cache files,
and store paths relative to the site-packages root so the archives can be restored later.
Packages whose names begin with "setuptools" or "pip" must be excluded from the export.
Upon completion, the script should print a success message along with a summary of how many files
were copied and how many directories were archived. ---
