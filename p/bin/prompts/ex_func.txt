Write a Python script that scans the current project directory recursively for Python source files
and extracts all top-level function definitions from each file, while skipping hidden directories,
virtual environment or package folders (such as site-packages),
and any previously generated output directory.
The script should parse each source file using an accurate syntax-aware parser so that only complete
top-level function definitions are captured, not classes, imports, or nested code.
Group the extracted function definitions by the folder in which their source files reside,
preserving the relative folder path as the grouping key,
and join the functions found in each file into a single text block.
Once all files are processed, the script should write the grouped results to an output location,
creating the output directory if it does not already exist,
with one output file per folder (or a clearly organized equivalent) containing the collected
function code so that a developer can review all top-level functions of each folder at a glance.
The script should handle files that cannot be read or parsed gracefully,
continue processing remaining files,
and report a concise summary of how many folders and functions were processed.
Keep the implementation clean, robust, and cross-platform,
and make reasonable choices about output formatting, naming, and error reporting. ---
