Write a Python script that takes a text file path
and a single target character from the command line,
then rewrites that same file in place with a cleaned version of its contents.
For each line of the file,
the script should remove surrounding whitespace and discard lines that are empty after trimming.
If a line contains the target character,
everything from the first occurrence of that character onward should be cut off,
keeping only the text before it.
Lines without the target character should be kept as their trimmed form.
The remaining lines should be saved back to the original file,
joined by newlines and encoded as UTF-8.
If no lines remain after processing, the file should be left unchanged.
The script should accept the file path and the target character as its two command-line arguments
and run only when executed directly. ---
