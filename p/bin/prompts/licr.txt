Write a Python script that scans the current working directory tree for license files
and clears their contents.
The script should recursively discover all regular files (skipping symbolic links),
identify those whose base name begins with "license" (case-insensitive) and
whose extension is either one of `.md`, `.txt`, `.rst`, or absent entirely.
For each matching file, print the file's base name and extension as it is processed,
then print a summary line stating how many license files were found.
Finally, overwrite every matched file with empty content encoded as UTF-8,
effectively truncating each license file to zero bytes.
The script should run as a standalone command-line tool with its main logic executed only
when launched directly.
Prioritize correctness and safety,
ensuring that non-matching files and symbolic links are left untouched. ---
