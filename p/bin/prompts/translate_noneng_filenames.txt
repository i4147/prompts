Write a Python script that recursively scans the current working directory
(and all of its subfolders) for files whose names contain non-English characters,
translates each such filename's base name (excluding the extension) into English using an online
translation service, and renames the file accordingly.
Files whose names are already plain ASCII/English should be left untouched.
The script should process the deepest folders first so that renaming does not disrupt traversal of
the directory tree.
Key requirements: - Start from the directory where the script is run,
with no required command-line input. - Detect non-English filenames by checking whether the base
name contains any non-ASCII characters;
skip everything else. - Translate the base name to English automatically,
with the source language auto-detected and the target set to English.
If translation fails,
print a clear error message that includes the filename
and keep the original name rather than crashing. - Preserve each file's original extension
and its location within its folder. - Avoid overwriting existing files:
if the translated name already exists in the same folder,
append a numeric counter (e.g., "_1", "_2")
until a free name is found. - Print a readable log line for each rename showing the old
and new names, and a final summary of how many files were renamed
and how many failed. - Handle errors gracefully so that a single failing file does not stop the
entire process. - Keep the implementation simple, dependency-light,
and compatible with modern Python 3 versions. ---
