Write a Python script that recursively walks through a given starting directory
and lazily yields the full path of every file and subdirectory it encounters,
traversing into subdirectories without following symbolic links.
The script should be designed to be iterated over in a memory-efficient manner,
producing paths one at a time rather than loading the entire directory tree into memory at once.
It should begin its traversal from the current working directory when run as a standalone program,
and for each path it finds,
it should check whether the entry is a regular file
and whether its name ends with a specific file extension supplied by the user
(for example, ".txt" or ".py").
Only matching files should be reported, and the script should print their full paths to the console.
The script should handle directories that cannot be read gracefully, without crashing,
and should be structured so that the directory-walking logic is reusable as a component in other
programs. ---
