Write a Python script that scans the current working directory recursively
and reports groups of files that share the exact same size,
helping the user spot potential duplicates.
The script should skip any files located inside version-control metadata folders (such as `.git`)
and ignore symbolic links and non-regular entries.
It should gather every regular file, group them by byte size,
and then output only the size groups that contain two or more files.
Results should be presented in ascending order of file size,
with each size shown as a clearly highlighted header followed by an indented list of the matching
file names.
Files with a unique size should not appear in the output.
The tool should run as a command-line program with no required arguments,
use colored terminal output for the size headers if available,
and exit cleanly with a status code when finished.
Handle file access errors gracefully so that an unreadable file does not crash the whole scan. ---
