Write a Python script that takes a text file path as a command-line argument,
reads the file line by line, trims surrounding whitespace from each line,
and converts the lines into a single brace-enclosed, comma-separated list of quoted string items.
For each line, use double quotes by default,
but switch to single quotes if the line itself contains a double quote character,
so the resulting literal remains valid.
Overwrite the original file with this formatted output using UTF-8 encoding.
Afterward, attempt to copy the formatted text to the system clipboard via the Termux clipboard
utility; if that utility is not available,
still keep the file update
but notify the user that the clipboard feature requires installing the Termux API.
On success, print a confirmation message that includes the file path
and indicates the content was updated and copied.
Handle the missing-clipboard case gracefully without crashing,
and make the script runnable directly as a standalone program. ---
