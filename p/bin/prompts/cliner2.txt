Write a Python script that recursively scans the current working directory
and all of its subdirectories for log files,
then cleans each one in place by stripping terminal control artifacts
and escape-sequence noise from every line.
The script should be a standalone command-line tool that requires no arguments
and runs from the directory where it is launched.
Key behaviors to cover:
- Discover every file ending in the ".log" extension anywhere beneath the starting directory.
If none are found, print a short message stating that no log files were present
and exit cleanly. - Report how many log files were found before processing begins. - For each log
file, read it using UTF-8 encoding,
tolerating and silently discarding any bytes that cannot be decoded.
Process it line by line. - Remove a predefined set of terminal-related noise patterns
from each line.
These include ANSI/VT100 escape sequences for colors, cursor movement, and character set selection;
caret-style escape representations; carriage returns; and shift-in/shift-out control characters.
Patterns should be matched robustly so that both raw escape bytes
and their textual representations are handled. - After stripping the noise,
collapse any run of two or more consecutive spaces into a single space,
while leaving single spaces
and the rest of the line content intact. - Overwrite each file with its cleaned content,
preserving line structure so that each original line maps to one cleaned line. - Print a clear
success marker with the file path for each file cleaned successfully,
and a clear error marker with the file path and the error reason if any file fails.
A failure on one file must not stop processing of the remaining files. - Use the output
and file-write encoding of UTF-8 so that non-ASCII text in logs is preserved. - Keep the tool
concise, robust, and safe to run repeatedly:
running it twice on the same files should produce the same result.
The output should be a readable console summary of the operations performed,
with no interactive prompts. ---
