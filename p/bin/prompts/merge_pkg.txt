Write a Python script that analyzes the source code of other Python modules in a project
and produces a consolidated, self-contained single-file bundle of them.
The tool should accept a root entry-point module path as input,
follow the project's internal (local) imports to discover every module it depends on,
and parse each module's structure to understand its top-level contents:
import statements, function definitions, class definitions,
module-level assignments (including any export list declarations),
and the main-guard block that runs when the file is executed directly.
The script should use static analysis of the source rather than executing the code,
so that it can safely process arbitrary files.
It should resolve which imported names refer to local project modules,
skip or flag third-party and standard library dependencies appropriately,
and detect circular dependencies without infinite looping.
The output should be a single standalone Python file that embeds all discovered local modules so
that the entry point can run without the original project directory present.
Each embedded module should be preserved faithfully
and registered so that imports within the bundle resolve to the embedded copies.
The script should also offer a way to encode module contents safely
(for example, in a text-friendly form) so the bundle remains valid and reproducible,
and it should write a clear summary to the console listing the modules discovered, their sizes,
and any warnings such as unresolved imports or potential name conflicts.
Handle errors gracefully:
report files that cannot be read, syntax errors, and encoding problems with clear messages,
and continue processing other modules where possible.
Accept command-line arguments for the entry-point path, the output file path,
and an optional flag to show a verbose analysis report without generating the bundle.
Ensure the generated output is deterministic so repeated runs on the same input produce
identical files. ---
