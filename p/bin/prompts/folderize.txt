Write a Python script that organizes files within a given root directory into alphabetically named
subfolders.
The tool should recursively scan the root directory for all regular files,
skipping anything located inside version-control metadata folders (such as `.git`).
Each file should be moved into a top-level subfolder named after the first character of its
filename: letters map to a folder named with that letter in lowercase,
while digits and any other characters (including empty or unusual names) are grouped into a single
shared folder labeled "0-9".
The script should default to operating on the current working directory when no root is specified.
Key behaviors to include:
- If no eligible files are found,
report that clearly to the user
and exit gracefully without making changes. - Report how many files were found before moving them,
and print a message for each file moved
or any error encountered. - Create destination folders as needed,
and handle name collisions safely so that no existing file is overwritten. - After moving files,
clean up any directories that became empty as a result, working from the deepest level upward,
while never deleting the root directory itself
or any non-empty directory. - Print a summary of the operations performed,
such as the number of files moved, skipped,
and failed. - Handle permission errors and other filesystem failures gracefully,
continuing with the remaining files rather than crashing. - Provide a command-line entry point that
accepts an optional target directory path and validates that it exists
and is a directory before proceeding. ---
