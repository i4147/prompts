Write a Python script that converts raw HTML documents into clean, readable plain text,
suitable for feeding into language models or downstream text-processing pipelines.
The tool should accept an HTML document (from a file path, a string, or standard input)
and produce a normalized text output, written to standard output or to a specified file.
Key behaviors to implement:
- Parse messy, real-world HTML robustly, tolerating malformed markup, missing closing tags,
and unknown elements. - Remove content that is not meaningful to a reader, such as scripts, styles,
metadata, hidden elements, comments,
and embedded non-text resources. - Preserve the logical structure of the document in the text
output: block-level elements such as headings, paragraphs, list items,
and divisions should be separated by line breaks,
while inline elements should flow within their line. - Render links in a readable way,
for example by keeping the anchor text and optionally including the target URL,
and render images using their alternative text
when available. - Convert simple structural elements such as list items
and table rows into readable plain-text representations,
with reasonable indentation or markers. - Collapse excessive whitespace and blank lines,
trim trailing spaces, and produce a tidy,
consistent result without losing meaningful text. - Provide a command-line interface with options to
control behaviors such as whether links include their URLs, whether images show alternative text,
the output destination,
and optional limits on line width or output length. - Handle character encoding gracefully,
and fail with clear,
user-friendly error messages when an input file is missing
or unreadable. - Keep the implementation self-contained, efficient on large documents,
and well-organized so the conversion logic is easy to extend with additional element handling. ---
