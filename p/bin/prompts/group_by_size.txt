Write a Python script that acts as a command-line folder organizer for the current
working directory.
The tool should discover all immediate subdirectories
(ignoring any that already follow a "group_" naming convention),
measure the total size of each subdirectory by recursively summing the sizes of all files within it
while gracefully skipping files or folders that cannot be accessed,
and report each folder's size in megabytes to the user.
It should then sort the subdirectories by size
and distribute them as evenly as possible into a user-specified number of balanced groups,
so that the combined size of each group is roughly equal.
Each group should be materialized as a newly created folder named with a "group_" prefix in the
current directory, with the corresponding subdirectories moved into it.
The script should accept the desired number of parts as a command-line argument,
validate that input sensibly,
and print clear progress and a final summary showing which folders ended up in each group
and the total size of each group.
Handle common error conditions such as missing subdirectories, permission problems,
and invalid arguments with helpful messages rather than crashes,
and design the behavior so that re-running the tool does not reorganize already-grouped folders. ---
