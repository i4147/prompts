Write a Python script that sc of its subdirectories,
looking for lines that define environment variables in the common `NAME=value` form,
where the name consists only of uppercase letters, digits,
and underscores and appears at the very start of the line.
Collect each distinct variable name found across all readable text files,
skipping any file that cannot be opened or decoded
and reporting the problem without stopping the run.
When the scan finishes, write the unique names to a text file named env_vars.txt, one name per line,
sorted alphabetically.
Finally, print a short summary to the console stating how many unique variable names were found and
where they were saved. ---
