Write a Python script that generates a set of human-readable,
memorable passphrases or word-based identifiers from a built-in word list,
with user-controllable options for how many words to use, separators, capitalization,
and optional numeric suffixes.
The tool should accept command-line arguments for the number of items to produce,
the word count per item, the separator to use,
and whether to include a random number or a deterministic seed-based output.
It should use a cryptographically secure source of randomness for generating selections,
support a default word list while allowing the user to supply a custom word list from a file,
and validate inputs with clear error messages.
Output should be printed to standard output one item per line,
with an option to write results to a file or emit them as JSON.
The script should also be able to generate unique random identifiers (such as UUIDs) as an
alternative output mode,
and should include a hashing utility that can produce a fingerprint of the generated output for
verification.
Handle edge cases such as empty word lists, insufficient words for the requested length,
and invalid arguments gracefully,
and provide a helpful command-line interface with a usage description. ---
