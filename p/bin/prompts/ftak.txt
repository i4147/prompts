Write a Python script that scans a directory tree for Python source files and reports which classes
and functions lack meaningful documentation.
The tool should accept a root directory path as its input,
recursively locate every Python file beneath it,
and analyze each file's structure without executing any of its code.
For each file that can be read as UTF-8 and parsed as valid Python,
it should identify all class definitions, synchronous functions, and asynchronous functions,
including nested ones, and determine whether each has a docstring.
Files that cannot be read, decoded,
or parsed should be skipped silently rather than halting the scan.
The output should be a clear, human-readable report listing every undocumented class or function,
grouped by file, with each entry showing the file path, the line number,
the kind of definition (class, function, or async function), and its name.
The report should also include a summary of total files scanned, total definitions examined,
and total undocumented definitions found.
The script should exit with a non-zero status when undocumented items are found and zero
when everything is documented,
so it can be used as a quality gate in continuous integration pipelines.
Make it robust to large projects,
handle invalid or missing root paths gracefully with a helpful error message,
and keep the scanning logic separate from the reporting logic so each can be extended
independently. ---
