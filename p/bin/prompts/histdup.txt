Write a Python script that cleans up the user's shell command history file by removing duplicate
entries while preserving the original order of first occurrences.
The script should locate the bash history file in the current user's home directory,
and if it does not exist,
inform the user with a clear message and exit gracefully without making changes.
When the file is found,
it should read the entire history using lenient text decoding so that malformed bytes do not crash
the process, report the total number of entries it contains,
and then rewrite the file so that each distinct command appears only once,
keeping the earliest occurrence of each and maintaining the original sequence.
Comparison between entries should ignore only the trailing newline character,
so that otherwise identical commands are treated as duplicates.
Finally, the script should report how many lines were removed.
Ensure the script runs as a standalone command-line tool with a conventional entry point,
returns a clean exit status,
and handles the file operations in a way that is safe and easy to understand. ---
