Write a Python script that manages a directory of pre-built Python wheel (.whl) packages,
identifying and removing outdated
or unwanted wheel files so that only the appropriate builds remain.
The script should scan a given directory (defaulting to the current working directory) for wheel
files and parse each filename to extract the package name, version, and target platform/Python tag.
It should recognize a specific set of supported platform tags,
including pure-Python "any" builds and several ARM Linux builds for Python 3.7 and 3.12.
Filenames that do not match the expected wheel naming convention should be ignored safely.
Key behaviors: - For packages that carry a date suffix in their version string
(for example, a trailing "-YYYYMMDD" stamp),
keep only the newest dated build of each package
and delete older dated builds. - Maintain a configurable blocklist of package names that must not be
installed as generic pure-Python "any" wheels;
any such wheels found should be removed, while other packages remain untouched.
- Only delete files that the script has positively identified as matching the criteria;
  never remove unrelated files
  or subdirectories. - Operate on the files passed in as a list of filenames
  and resolve them against the target directory,
  so the cleanup logic can be called programmatically as well as run from the command line. - Report
  clearly to the user which wheel files were kept and which were removed,
  and handle missing directories
  or permission errors gracefully with informative messages rather than crashing. - Provide a safe
  dry-run option so the user can preview deletions before they happen.
The output should be a deterministic cleanup of the wheel directory,
with a concise summary of actions taken. ---
