Write a Python script that scans a given directory tree recursively and reports
which Python source files lack a proper script entry-point guard
(the conventional conditional block that runs code only
when the file is executed directly rather than imported).
The script should accept a directory path as its main input,
traverse all files within it (including nested subdirectories), and identify every Python file.
For each Python file, it should read the source safely, handling encoding problems, I/O errors,
and syntax errors gracefully by reporting a warning to the error stream
and treating the file as already compliant so it is not flagged.
It should analyze the file's structure rather than relying on plain text matching,
detecting whether a conditional check compares the module's special name variable against the string
representing the main program, accounting for both orderings of the comparison operands.
The output should be a clear summary listing the paths of Python files that are missing the
entry-point guard, along with a total count of files scanned and files flagged.
Suppress unnecessary runtime warnings so the output stays clean.
The script should run from the command line,
print helpful messages for missing or invalid directory arguments,
and exit with a non-zero status when the input path is invalid.
Keep the design modular and readable, and include a brief usage explanation in the help output. ---
