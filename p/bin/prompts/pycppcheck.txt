Write a Python script that checks the syntax of C
and C++ source files using the system's Clang compilers.
The tool should accept an optional list of file paths from the command line;
if none are given, it should automatically discover all C and C++ source
and header files (including common extensions such as .c, .h, .inc, .cpp, .cc, .cxx, .hpp, .hh,
.hxx, and .hpp11) under the current working directory.
For C-family files, use the C syntax-only check;
for C++ files, use the C++ syntax-only check, without generating any object or output files.
The script should run these checks concurrently using a bounded pool of worker processes
(around eight workers),
keeping a limited number of tasks in flight at once so that memory use stays controlled on
large projects.
Each file's result should capture the file path, the compiler's exit code,
and its standard output and error text.
After all checks complete, the script should report the results clearly to the user:
list each file that failed with its diagnostic output,
and provide a summary showing how many files passed and how many failed.
The script should exit with a non-zero status if any file fails validation and zero if all pass.
Handle missing compiler binaries
or unreadable files gracefully with informative messages rather than crashing. ---
