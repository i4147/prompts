Write a Python script that recursively scans the current working directory
and all of its subdirectories for files named "setup.py",
and updates any ABI version tag that is embedded in them to match the Python interpreter version
currently running the script.
Specifically, each setup file may contain a wheel or platform declaration of the form "python,
abi=..." where the ABI tag follows the pattern "cp3" followed by one or more digits;
the script should replace that existing tag with a tag corresponding to the running interpreter's
minor version (for example, "cp311" for Python 3.11), while leaving the rest of the file untouched.
The script should behave as follows:
- Process every matching setup file found anywhere beneath the starting directory,
not only the top level. - Only rewrite a file when its content actually changes,
and skip files that contain no matching declaration. - Read and write files using UTF-8 encoding,
preserving all other text exactly as it appears. - For each file that is updated,
print a short confirmation line showing the file's path relative to the starting directory,
using a check mark prefix. - If an error occurs
while handling a particular file (for example, due to permissions or encoding problems),
print an error message identifying that file and the reason,
then continue processing the remaining files rather than aborting. - When finished,
print a summary line stating how many files were updated and
which target ABI tag was applied. - The script should run its main logic only
when executed directly as a program, not when imported as a module. ---
