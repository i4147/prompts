Write a Python script that acts as a command-line utility for uninstalling pip packages in bulk.
The tool should accept one or more package names as command-line arguments
and uninstall them from the current Python environment without requiring interactive confirmation.
It should also support an optional wildcard mode, triggered by a leading flag,
in which each supplied term is treated as a substring pattern that matches any installed package
whose name contains that text (case-insensitive).
In wildcard mode, all matching installed packages should be collected and uninstalled together,
with duplicates removed.
In normal mode, package names should be matched case-insensitively against the installed packages so
that the user can supply names in any casing,
and the canonical installed name should be used when uninstalling.
Inputs: command-line arguments consisting of an optional wildcard flag followed by one
or more package names or substring patterns.
Outputs and behavior:
if no arguments are given, or if wildcard mode is requested without any patterns,
the script should print a brief usage message showing the expected syntax
and exit with a non-zero status.
The script should enumerate the packages installed in the active environment,
report any requested packages that are not installed,
and perform the uninstall for the resolved set.
It should return or exit with the status code produced by the underlying uninstall operation so that
success or failure is reflected to the caller.
Provide clear, concise console messages describing what was matched, what was skipped,
and what is being removed.
Handle the case where nothing matches gracefully by informing the user
and exiting without attempting an uninstall. ---
