Write a Python script that scans the immediate subdirectories of the current working directory
and checks each one for Lua source files (files with a .lua extension, searched recursively).
For every subdirectory that contains no Lua files,
the script should print its name in a simple bulleted list format.
The script should also provide a way to relocate Lua-containing plugin directories:
when a directory contains Lua files,
it should be copied into a fixed Vim plugin location inside the Termux home directory
(under a pack/plugins/start path, creating any missing parent folders as needed),
and the original directory should then be removed after the copy completes.
Handle the case where the destination already exists gracefully, skip non-directory entries,
and ensure the script runs as a standalone program when executed directly, with clear,
readable console output. ---
