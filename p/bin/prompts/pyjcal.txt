Write a Python script that converts and displays dates in the Persian (Jalali/Solar Hijri) calendar.
The tool should accept Gregorian dates
(defaulting to the current date and time when none are supplied) and convert them into Jalali year,
month, and day, along with the corresponding Persian weekday name.
It should support output in both English and Persian (Farsi) transliterations and script,
including month names and weekday names, and allow the user to choose which language to display.
The tool should also be able to report the current Jalali date together with the current time,
and provide a way to format the result as a readable string.
Design it as a reusable component so that other programs can import the date conversion logic,
while also offering a simple command-line interface for quick lookups.
Handle invalid or out-of-range input gracefully with clear error messages,
and ensure the Gregorian-to-Jalali conversion is accurate across the full range of common
calendar years.
Choose a clean, well-organized structure with clear documentation so the code is easy to maintain
and extend. ---
