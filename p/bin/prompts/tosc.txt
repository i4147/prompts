Write a Python script that acts as a command-line file collector and mover.
It should accept one or more file paths or glob patterns as arguments,
plus an optional fl file that contains a list of paths
or patterns (one per line, ignoring blank lines).
When run with no arguments,
it should print a short usage message to standard error and exit with a non-zero status.
For each resolved input,
the script should locate the matching files
(supporting recursive glob matching, and treating an existing literal path as a direct match)
and ignore anything that is not a regular file.
It should then move or copy each collected file into a fixed destination folder located in the
user's home directory under a nested "isaac/may/scripts" path,
creating that folder if it does not already exist.
If a file with the same name already exists at the destination,
the script must avoid overwriting it by generating a unique alternative name.
The script should report clearly to the user what it did:
the number of files processed, each destination written,
and any paths that matched nothing or failed,
with errors written to standard error rather than halting the entire run.
Handle missing list files and missing flag arguments gracefully with helpful error messages
and a non-zero exit code.
Use the command line as the sole interface,
and keep the behavior deterministic so that repeated runs with the same inputs produce predictable
results. ---
