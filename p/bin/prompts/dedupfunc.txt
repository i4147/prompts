Write a Python script that scans one or more Python source files,
identifies functions that are duplicates of each other,
and reports them so a developer can clean up redundant code.
The tool should accept a file path or directory as input, walk through all Python files found,
and parse each one to extract every function definition along with its location
(file and line number).
For each function, the tool should derive a normalized representation of its body that ignores
superficial differences such as comments, blank lines, and surrounding whitespace,
so that functions differing only in formatting or commentary are still recognized as duplicates.
Functions whose normalized bodies match exactly should be grouped together,
and the tool should report each group with the names, file locations,
and line numbers of all matching functions.
The script should handle common edge cases gracefully:
files with syntax errors should be skipped with a warning rather than crashing the run,
empty or trivial function bodies (such as a lone pass or docstring) may optionally be excluded from
comparison, and nested functions and class methods should be included in the analysis.
The output should be a clear,
human-readable report listing each duplicate group and a summary count of duplicates found,
with an optional machine-readable format such as JSON selectable via a command-line flag.
The tool should exit with a non-zero status code
when duplicates are found so it can be integrated into continuous integration pipelines,
and it should provide a command-line interface with helpful usage information
and a way to set a minimum function length threshold to filter out very short functions. ---
