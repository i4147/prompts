Write a Python script that batch-converts HTML files into clean Markdown documents.
The tool should accept a directory or a set of file paths, locate HTML files within them,
and for each file extract only the main readable article content
(stripping navigation, ads, sidebars, and boilerplate),
then convert that content into Markdown
and save it alongside the original file using the same base name with a .md extension.
Key behaviors: - Skip any file for which a Markdown counterpart already exists,
reporting it as already processed rather than reprocessing it. - Read input files tolerantly,
ignoring or replacing undecodable characters so that malformed HTML does not halt processing. - Only
write the Markdown output if meaningful text was extracted;
if the result is empty or whitespace-only,
report that no content could be extracted
and leave the source untouched. - Provide a configurable option to delete the original HTML file
after a successful conversion,
enabled by default. - Handle errors per file so that a failure on one document is reported with a
clear message and does not stop processing of the remaining files. - Print a concise,
human-readable status line for each file:
a success indicator with the converted filenames, a warning for files with no extractable content,
and an error indicator with the reason for failures. -
When run from the command line with no arguments,
default to processing the current working directory;
otherwise process the paths supplied by the user. - Return a clear result for each processed file
indicating the resulting output path and whether the conversion succeeded,
so the results can be summarized at the end (e.g., total converted, skipped, and failed). - Target
UTF-8 output and preserve the original text's encoding and characters in the Markdown. ---
