Write a Python script that displays an image directly in the terminal using colored block
characters.
The script should take a single image file path as a command-line argument.
If no path is provided, it should print a brief usage message and exit gracefully.
When given a valid image, the script should open it, convert it to a standard color format,
and scale it to fit the full width of the current terminal window
while preserving the original aspect ratio.
Because terminal character cells are taller than they are wide,
the vertical scaling should be adjusted so the image does not appear stretched.
The output should render two vertical pixels per character row using a half-block glyph,
with the top pixel shown as the foreground color and the bottom pixel as the background color,
using 24-bit ANSI true-color escape sequences.
Each row of the rendered image should be followed by a reset of terminal styling so colors do not
bleed into subsequent output.
The script should handle common image formats supported by a standard imaging library,
and it should work with images of any size, including very small and very large files.
Output should go straight to standard output so the result can be viewed immediately in any
true-color-capable terminal.
Keep the script self-contained, readable, and runnable as a standalone command-line tool. ---
