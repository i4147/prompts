Write a Python script that splits a text file into a specified number of roughly equal parts,
saving each part as a separate new file alongside the original.
The tool should accept two inputs:
the path to a source file and a positive integer indicating how many parts to produce.
Before splitting, it must check whether the file is binary;
if so, it should print a clear error message to the error output stream
and exit with a non-zero status without creating any files.
The file should be read as UTF-8 text, and the split should be made by lines,
so that each part contains complete lines only and the content of all parts, concatenated in order,
reproduces the original file exactly.
Each output file should be named after the original file's base name with a zero-padded sequence
number inserted before the original extension
(for example, a file named report.txt split into three parts yields report_1.txt, report_2.txt,
report_3.txt, with the padding width matching the number of digits in the requested part count).
All output files should be written to the same directory as the source file,
and the tool should report each created file's path to standard output as it is written.
Distribute lines as evenly as possible across parts;
any remainder lines should be absorbed by the final part.
The tool must reject a part count that is zero
or negative by raising a clear error with a descriptive message.
If the number of requested parts exceeds the number of lines in the file,
the behavior should be handled gracefully, and the tool should not crash.
Provide a command-line entry point that validates its arguments,
prints concise usage guidance when arguments are missing or malformed,
and exits cleanly on success or failure. ---
