Write a Python script that converts a CSV file into a JSON file.
The script should accept the path to an input CSV file as a command-line argument
and produce a JSON file saved alongside it, using the same base name with a .json extension.
Each row of the CSV, with its first line serving as the column headers,
should become one record in the output, and the output should be a JSON array of these records.
The script should read and write using UTF-8 encoding,
preserve non-ASCII characters as-is in the output rather than escaping them,
and format the JSON with readable indentation.
If the user runs the script without providing an input file argument,
it should print a brief usage message to the console and exit with a non-zero status code.
Ensure the script can be run directly from the command line
and exits cleanly after completing the conversion. ---
