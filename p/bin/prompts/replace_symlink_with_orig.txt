Write a Python script that scans a given directory tree for symbolic links
and replaces each eligible symlink with a real copy of its target,
so the directory becomes self-contained.
The tool should accept a root directory path as input
and process all symlinks beneath it in parallel using a bounded number of worker processes
(around eight by default).
For each symlink, it should resolve the target whether the link is absolute
or relative to the link's location.
Symlinks that point to files
or directories should be replaced by a full copy of the target
(directories copied recursively, files copied with metadata preserved),
after the original link is removed.
Skip symlinks that are special cases the user would not want touched:
links located in a "bin" directory that point to a sibling in the same directory,
and links pointing to shared library files with a ".so" extension.
If a symlink's target no longer exists, record an error rather than failing the run.
Log successfully replaced links to a file named "replaced.txt" in the output or working location,
and log all failures and broken links to a file named "errors.txt".
Use a logging facility that reports progress and warnings to the console as well.
The script should print a concise summary at the end showing how many links were replaced, skipped,
and failed.
It should handle unexpected exceptions per item without aborting the entire batch,
and it should be safe to run as a standalone command-line tool with clear usage guidance if the
input path is missing or invalid. ---
