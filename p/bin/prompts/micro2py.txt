Write a Python script that acts as a command-line refactoring tool for cleaning up files whose names
or contents carry an unwanted "u" prefix on standard library module names.
The tool should accept one or more file
or directory paths (with directories processed recursively for Python source files)
and a dry-run option that reports intended changes without modifying anything.
For each Python file it processes, the tool should:
- Detect identifiers in the text that begin with a lowercase "u" immediately followed by the name of
a Python standard library module, and rewrite them to drop the leading "u",
while leaving any other identifiers untouched.
Matching must respect word boundaries so that unrelated words are not altered. - Determine whether a
given module name belongs to the standard library in a way that works across Python versions,
preferring an official list when available
and falling back to a module-lookup check otherwise. - Rename files
whose stem starts with "u" followed by a standard library module name,
dropping the leading "u" from the filename while preserving the extension,
and avoid overwriting any existing file with the target name. - Save content changes only
when the text actually differs,
and report a clear summary of each file that was modified or renamed,
including counts of changed files
and renamed files at the end. - Handle errors gracefully
(unreadable files, encoding issues, permission problems) by logging a message
and continuing with the remaining files, returning a nonzero exit status if any failures occurred.
The output should be a self-contained, well-structured command-line utility with helpful usage text,
clear console reporting, and safe default behavior that never silently destroys data. ---
