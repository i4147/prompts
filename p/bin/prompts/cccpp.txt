Write a Python script that removes comments from C and C++ source files
while preserving the code's behavior and overall layout.
The tool should accept one or more file or directory paths as input,
recursively discover C and C++ source
and header files (common extensions such as .c, .h, .cc, .cpp, .cxx, .hpp, .hh, .hxx, .inl),
and process them in parallel using a configurable number of worker processes (default 8) to speed up
large codebases.
For each file, the script should use an accurate syntax-aware parser for the appropriate language
(C or C++, selected by file extension) so that only true comments are identified,
and comment-like text inside string literals, character literals, or raw strings is left untouched.
Comments of both styles (line comments and block comments) should be removed.
Where a removed comment leaves a line empty, the blank line should be dropped,
and any trailing whitespace left behind should be cleaned up.
Preserve preprocessor directives, include statements, and all non-comment tokens exactly as written.
The script should support a dry-run or preview mode that reports
which files would change without modifying them,
an option to write output to a separate destination directory instead of overwriting originals,
and a summary at the end listing how many files were processed, modified,
skipped (unsupported or unreadable), and how many comments were removed.
Errors on individual files should be logged clearly with the file path and reason,
and must not stop processing of the remaining files.
Use structured logging with appropriate verbosity levels,
and return a non-zero exit code if any file failed to process.
The output should be the cleaned source files with identical encoding
and line endings as the originals where feasible,
and the tool should be runnable from the command line with clear help text describing all
options. ---
