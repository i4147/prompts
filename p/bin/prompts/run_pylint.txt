Write a Python script that acts as a command-line lint runner for Python source files.
It should accept zero or more file and/or directory paths as command-line arguments.
For each file given, it lints that file;
for each directory given, it discovers all Python source files within it and lints each of those.
If no arguments are provided,
it should default to discovering and linting all Python files in the current working directory.
For every Python file targeted,
the script should run the pylint static analyzer in a non-persistent, reports-suppressed mode,
producing machine-parseable output
where each message is formatted as a colon-separated line containing the message category,
line number, column, object name, message text, and message identifier.
Lint output should be displayed directly to the user as it is produced,
and the script should process each file in turn, reporting results for all of them.
The script should be a self-contained utility that relies on a small helper module for file
discovery and running external shell commands.
It should exit cleanly with a standard process exit status when finished,
and it should be runnable directly as a script entry point. ---
