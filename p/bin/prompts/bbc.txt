Write a Python script that cleans up Python packaging build artifacts from the current working
directory and its subdirectories.
The tool should recursively scan the project tree and remove generated build leftovers,
including build output folders, distribution folders, and common build target directories,
as well as egg-info metadata directories and package metadata files left behind by packaging tools.
It should also inspect configuration files named setup.cfg
and remove only those that contain a specific,
minimal egg_info configuration (an empty build tag and a zero date tag),
leaving any other setup.cfg files untouched, so that user-authored configuration is never deleted.
The script should report each removal to the user with a short,
clear message identifying what was deleted,
handle file reading safely (for example, tolerating files that cannot be decoded or are malformed),
and avoid crashing when encountering unexpected or partially matching content.
It should be designed to run as a standalone command-line utility that is safe to execute
repeatedly, and should prioritize avoiding accidental deletion of source code or user data. ---
