Write a Python script that scans an HTML document
(provided as a file path given on the command line, or read from standard input) for embedded
base64-encoded data URLs, such as inline images, fonts, or other assets,
and extracts each one into a local output folder as a separate file.
For every data URL found, the script should identify its MIME type,
decode the base64 payload
(tolerating whitespace and line breaks inside the encoded text,
and skipping any entries that fail to decode without stopping the whole run),
and save the result using a file extension appropriate to that MIME type.
Output filenames should be derived from a short,
stable hash of the decoded content so that identical assets are not duplicated
and names remain unique.
The script should create the output directory if it does not exist,
report to the user how many assets were extracted and where they were saved,
and handle common errors gracefully with clear messages
(such as a missing input file or an unreadable HTML source).
Keep the design simple, robust, and easy to run from a terminal,
and rely on the standard library wherever practical,
leaving the internal structure and implementation choices entirely to you. ---
