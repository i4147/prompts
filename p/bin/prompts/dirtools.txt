Write a Python script that analyzes a directory tree and reports disk usage in a human-friendly way.
The tool should accept a target directory path (defaulting to the current working directory)
and options controlling whether to scan recursively, whether to include hidden files and folders,
and which file or folder names to exclude from the analysis.
It should compute the total size of the files under the target
and break that total down by subdirectory,
showing how much space each immediate child folder consumes,
with the largest consumers listed first.
It should also be able to summarize the file population,
such as the number of files found and the most common file extensions or sizes.
Sizes must be presented in compact,
readable units (bytes, kilobytes, megabytes, gigabytes, terabytes),
with negative values handled gracefully.
The output should be a clear plain-text report printed to the console,
with aligned columns and a header describing the scanned path and totals.
The tool should allow the user to limit how many entries are displayed,
to sort or rank results by size,
and to choose between a concise summary and a more detailed listing.
Handle unreadable paths, missing directories,
and permission errors gracefully by skipping problematic entries
and reporting warnings without crashing.
Symbolic links should not be followed or counted as regular file sizes.
The script should be runnable from the command line with a help message describing all available
options, and it should exit with a meaningful status code on fatal errors such as a nonexistent
target path. ---
