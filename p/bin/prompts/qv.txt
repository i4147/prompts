Write a Python script that acts as a command-line file viewer for the current working directory,
displaying the contents of every file in a paged, scrollable format.
By default, the tool should list only the files located directly in the current directory.ursive
option is provided on the command line,
it should also include files found in all subdirectories beneath it.
Files should be presented in a stable, case-insensitive alphabetical order based on their paths.
For each file, the output should clearly show a visually distinct header containing the file's path
relative to the starting directory, followed by the file's text content.
Content should be read as text in a tolerant way so that files with unusual
or invalid characters still display without crashing.
If a file cannot be read due to a system or permission error,
the tool should display a brief message in place of its contents
and continue processing the remaining files rather than stopping.
If no files are found, the tool should print a short message indicating that and exit cleanly.
The overall output should be delivered through a pager so the user can scroll
and navigate through large amounts of content comfortably,
with the entire combined output presented asuous, readable document.
Provide a help description accessible from the command line that explains the purpose of the tool
and its recursive option. ---
