Write a Python script that reads a plain text file from a path given as a command-line argument
and reads its contents aloud using the device's text-to-speech system
(intended for Android/Termux environments).
The script should print a brief usage message and exit with an error if no file path is provided,
and report a clear error and exit if the file does not exist.
Because text-to-speech engines handle only limited input length per call,
the script must split the file's content into sequential chunks of at most roughly 3000 characters
each, preferring to break on line boundaries so that sentences and lines stay intact;
any single line longer than the limit must be further split into pieces of the maximum size.
Empty or whitespace-only lines should be ignored.
Each chunk should be spoken in order, one after another,
waiting for each to finish before starting the next,
and any failure from the speech system should be surfaced as an error to the user.
The script should be runnable from the command line as a simple tool with no interactive
prompts. ---
