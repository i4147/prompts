Write a Python script that creates a starter HTML file from a built-in template.
The script should run from the command line,
accept an optional output file path as its first argument,
and default to creating a file named index.html in the current directory when no path is given.
When run, it writes a minimal HTML5 boilerplate page with a title "html template",
a linked stylesheet named style.css and a linked script named script.js in the document head,
and a body containing a div with a level-two heading reading "Heading2".
The file must be saved using UTF-8 encoding.
The script should be a simple,
self-contained command-line utility that produces the file silently on success,
with no additional output,
and should handle the case where the provided path is invalid
or cannot be written by reporting a clear error message to the user. ---
