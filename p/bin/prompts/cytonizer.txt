Write a Python script that acts as a batch build helper for Cython extension sources.
The script should accept zero or more command-line arguments,
where each argument may be either a path to an individual Cython source file or a directory.
When given a directory, it should discover all Cython source files within it;
when given a file, it should use that file directly.
If no arguments are provided,
it should search the current working directory for Cython source files.
Each discovered source file should be compiled by invoking the Cython compiler on it from within
that file's own directory, so that generputs land alongside the source.
The compilation of multiple files should be carried out in parallel using a small pool of worker
processes (around four).
The script should restore its original working directory when finished,
handle missing or invalid paths gracefully,
and exit cleanly with a status code when run as the main program.
Keep the implementation simple and dependable, relying only on the standard library where practical,
and report progress or errors to the user in a concise way. ---
