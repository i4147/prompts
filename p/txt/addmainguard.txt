Write a Python command-line utility script that scans Python source files to check for the presence
of the standard `if __name__ == "__main__":` entry-point guard,
and optionally adds it automatically.
The script should: 1. **Purpose**:
Detect Python files that lack a `__main__` guard,
and optionally insert one (along with a stub `main()` function if missing) to enforce good scripting
practices across a codebase.
2. **Main inputs**: - One or more file paths
or directory paths (to be scanned recursively for `.py` files) passed as command-line arguments via
`argparse`. - An `--add` flag to actually modify files that are missing the guard
(instead of just reporting them). - A `--dry-run` flag to simulate the `--add` behavior without
writing any changes,
showing what would be modified. - Support for processing multiple files concurrently using
`ProcessPoolExecutor` (leveraging `multiprocessing.cpu_count()` or similar) for performance on
large codebases.
3. **Main outputs**:
- For each processed file, print a status indicating whether the file already has a guard (skipped),
is missing a guard (missing/reported), would have a guard added (dry-run),
or had a guard successfully added (added),
including error handling for unreadable/unwritable files. - A final summary showing counts of each
category (e.g., total files scanned, number missing guards, number modified, number skipped,
number of errors). - Appropriate process exit code
(e.g., non-zero if files are missing guards and `--add` was not specified,
useful for CI/lint-style checks).
4. **Notable behavior**:
- Use a regex to detect existing `if __name__ == "__main__":` guards
(supporting both single and double quotes, and flexible whitespace). - When adding a guard,
first check if a `main()` function already exists in the file;
if not, insert a stub `def main():` function
(with a placeholder `print` statement and a `TODO` comment) right after the initial block of
top-level `import`/`from` statements.
- Append the guard code `if __name__ == "__main__":\n raise SystemExit(main())` at the end of the
  file content (after stripping trailing whitespace),
  ensuring idempotency (don't duplicate guards or `main()` functions if they already exist). - Read
  and write files using UTF-8 encoding. - Handle errors gracefully per-file
  (e.g., permission errors, decoding errors) without crashing the whole batch process,
  reporting them in the final summary instead.
