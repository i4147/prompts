Write a Python command-line script that deletes a range of lines from a text file.
It should accept a filename as the first argument, a starting line number as the second argument,
and an optional ending line number as the third argument;
if the ending line number is omitted, deletion should continue through the last line of the file.
The script reads the file, removes the specified 1-indexed inclusive line range,
writes the remaining lines back to the same file,
and prints a message showing how many lines remain.
