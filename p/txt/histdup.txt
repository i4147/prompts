Write a Python script that deduplicates the user's bash history file located at ~/.bash_history.
It should check if the file exists and print a message and exit if not, otherwise read all lines,
print the original line count,
and remove duplicate lines while preserving the first occurrence and original order.
The script should then overwrite the history file with the deduplicated lines
and print how many lines were removed,
using UTF-8 encoding with error tolerance when reading the file.
