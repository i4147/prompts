Write a Python script that scans the current working directory
and its subdirectories to find Python scripts lacking a file extension.
It should use helper functions from a module named "dh"
(get_filez, is_binary, is_python_file, should_skip) to enumerate files,
skip irrelevant or binary entries,
and identify files that start with a shebang line ("#!") and are recognized as Python files.
The script defines a helper to check for a shebang by reading the first two bytes of a file,
and a main function that collects matching extensionless Python scripts into a list.
When run directly, it prints the relative paths (relative to the current directory) of all found
scripts, or a message indicating none were found if the list is empty.
