Write a Python script that converts a WebVTT subtitle file into SRT format.
It should take a VTT file path as a command-line argument, read its contents,
strip the "WEBVTT" header, then parse each cue block by detecting lines containing "-->" timestamps,
converting the timestamp separator from periods to commas,
and prefixing each cue with a sequential numeric index as required by SRT.
The converted subtitle text should be written to a new file with the same name
but a ".srt" extension, and the script should print a confirmation message once the file is saved.
