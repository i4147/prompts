dir_tools.py — unified directory analysis & folderization toolkit.
Merges the following original scripts into one CLI:
dirinfo.py -> info dirinfo2.py -> subdirs --chart bar visdir.py -> subdirs --chart pie --top-n 0
--min-kb 0 pddd.py -> list pytree.py -> tree foldesiz.py -> split-range foldesize.py -> split-count
foldsize.py -> split-greedy foldsize2.py -> split-even Third-party packages
(only needed for chart output):
matplotlib Usage examples -------------- python dir_tools.py info ./mydir --save-report .dirinfo
--chart sizes.png python dir_tools.py subdirs ./mydir --chart pie --top-n 15 --min-kb 50 python
