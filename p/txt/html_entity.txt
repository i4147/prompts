Write a Python command-line script that recursively processes text files
(either passed as CLI arguments
or discovered via a helper `get_nobinary` function that lists non-binary files under the current
directory) and replaces common HTML entities (like `&lt;`, `&amp;`, `&nbsp;`, `&mdash;`, etc.) with
their corresponding Unicode characters using a precompiled regex and lookup table.
It should read each file as UTF-8, only rewrite the file if content actually changed,
use `multiprocessing` to process files in parallel for performance,
and track/report which files were changed versus which raised errors during processing.
