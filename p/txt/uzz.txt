Python equivalent of: for f in *.whl;
do unzip $f rm -v $f done Behavior:
* Iterate over every .whl file (a .whl is just a ZIP archive) in the target directory. * Extract
each archive into the same directory that contains it. * Delete the original .whl **only if
extraction succeeded**. * Any error is logged via `loguru` and the original .whl is preserved.
