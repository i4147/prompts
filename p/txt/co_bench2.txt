Compression benchmark with level sweeps.
Usage: python bench_compression.py <file_or_folder> [options] Options:
--runs N Timing runs per (algo, level) (default: 3) --sweep Sweep all default levels per algorithm
--levels K=V,...
Override specific level keys (single level per algo) --algorithms A,B,...
Substring filter on algorithm name --no-decompress Skip decompression benchmark --csv OUT.csv Also
write results to CSV
