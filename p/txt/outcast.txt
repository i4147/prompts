Write a Python script that scans a given source directory
(defaulting to the Telegram app's cache folder on Android,
`/sdcard/Android/data/org.telegram.messenger/cache`),
finds the single largest file within it by size, and copies its contents to a destination file.
The destination file should be placed in `/sdcard/Download/`
and named with a random 6-letter lowercase string plus a `.mkv` extension,
generated via a helper function.
After copying, the script should print the destination filename along with the copied file's size
in megabytes.
The copy should be performed by reading all bytes from the largest file
and writing them to the destination path.
