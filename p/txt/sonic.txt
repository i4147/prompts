Write a Python command-line script that reads one or more text files efficiently
and reports line-count statistics.
It should include a LineProcessor base class with a verbose logging helper and a file-size lookup,
plus an MmapReader subclass that memory-maps files larger than 1MB
(falling back to normal reads for smaller files by one via a generator,
decoding with a configurable encoding and optionally skipping empty lines.
The script should accept command-line arguments (via argparse) for input file path(s), encoding,
verbosity, and an option to skip empty lines,
then aggregate results such as total line counts and timing using modules like json, time, datetime,
Counter, and a custom fsz helper for human-readable file sizes,
writing output to stdout or a specified location
while using temporary files/directories as needed for intermediate processing.
