Write a Python utility script that recursively finds
and extracts common archive formats (zip, whl, tar, tar.gz/tgz, tar.bz2/tbz2, tar.xz/txz, and 7z)
within a given directory.
For each archive found, it should create a safely-named,
non-colliding output folder
(appending an incrementing suffix like "_1", "_2" if the target name already exists)
and extract the archive's contents into it,
using the appropriate library (tarfile, zipfile, or py7zr) based on the file extension.
The extraction functions should return a boolean success indicator
and gracefully handle exceptions such as corrupted
or unsupported archive files without crashing the script.
Include necessary imports (shutil, tarfile, zipfile, pathlib.Path, py7zr) to support these file
operations.
