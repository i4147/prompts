Write a Python script that reads a text file
whose path is provided as the first command-line argument,
streaming its lines one at a time using a generator function.
For each line, pass it through the `faprint` function imported from the `faprint` module,
and print the returned result to standard output.
The script should process the file lazily line-by-line rather than loading it all into memory at
once, and assumes the file is UTF-8 encoded.
