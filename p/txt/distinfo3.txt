Python version dynamically
and locates the corresponding site-packages path under
"/data/data/com.termux/files/usr/lib/pythonX.Y/site-packages".

it should print the directory name, and if the directory name contains "dist-info",
check whether it holds a "top_level.txt" or "entry_points.txt" file;
if so, print a cyan-colored message via a "cprint" function imported from a local "dh" module
indicating the direct the entire directory using shutil.rmtree script should exit gracefully
(doing nothing) if the target site-packages path does not exist,
and should run its main logic when executed as a script, returning the result via SystemExit.
