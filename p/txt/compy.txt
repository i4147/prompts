Minify and compress Python source code.
Pipeline (per file): 1.
Parse into an AST.
2. Strip docstrings, type hints, and annotated assignments.
3. Strip stdlib imports (recorded for a trailing notice).
4. Shorten user-defined identifiers (a, b, ..., z, a1, ...).
5. Peephole optimize:
augmented assigns, nested-if merge, dead code removal, else-after-terminator flattening,
constant folding, `if x: return True / return False` -> `return bool(x)`.
6. `ast.unparse` and join adjacent simple statements with `;`.
Output: * One input file -> <stem>_compressed.py (zlib+base85 stub) * Multiple inputs ->
compressed.txt (readable minified) compressed_stub.py (zlib+base85 stub)
