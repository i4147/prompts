Write a Python script that recursively searches the current working directory for all files with a
.whl extension.
For each wheel file found,
it should copy its contents to a fixed destination folder at /sdcard/whl using the same filename,
overwriting any existing file with the same name at that location,
and then delete the original source file.
As each file is moved,
the script should print a line showing the source filename mapped to the destination filename,
and after processing all files it should print "done" to indicate completion.
