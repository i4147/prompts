Write a Python command-line tool that scans one
or more Python source files (optionally recursively across a directory) to detect comments
and docstrings, using the ast and tokenize modules to parse each file's syntax tree
and token stream.
For each file it should identify standalone comment lines (ignoring shebang lines)
and string literals that serve as module/class/function docstrings,
reporting the line number and a truncated preview of each finding.
It should support multiprocessing to check multiple files in parallel for performance,
take input paths via argparse,
and print a per-file list of issues (comments/docstrings found) to help enforce a "no
comments/docstrings" coding style policy.
