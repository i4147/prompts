Write a Python CLI script that downloads a GitHub repository as a zip archive using the PyGithub
library, authenticating via a GITHUB_TOKEN environment variable
(optionally loaded from a .env file in the user's home directory).
It should accept the target username, repository name, branch (default "main"),
and optional output filename as arguments, then connect to the repo,
fetch the zipball for the specified branch, save it to disk,
and print progress messages including download size in MB and the final saved file path.
The script must handle missing token
and GitHub API errors gracefully by logging clear error messages
and returning None instead of crashing,
and should use argparse for command-line argument parsing
and logging/print statements for user feedback with emoji indicators for success and failure states.
