Write a Python command-line script that takes a file path
and a target character as arguments (sys.argv[1] and sys.argv[2]).
It should read the file's lines, and for each non-empty line, if the target character is found,
truncate the line at that character's first occurrence; otherwise keep the stripped line as is.
Empty lines should be discarded.
Finally, the script should overwrite the original file with the processed lines joined by newlines,
using UTF-8 encoding, only if there is at least one resulting line.
