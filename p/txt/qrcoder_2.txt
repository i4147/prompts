Write a Python command-line script that extracts
and decodes QR codes from an image file provided as a single command-line argument.
It should open the image with Pillow, convert it to RGB if needed,
and use pyzbar to detect and decode any QR codes present,
filtering results to only the "QRCODE" type.
The script must validate that exactly one argument is given and that the file exists,
printing usage or error messages otherwise,
and gracefully handle exceptions during decoding by printing an error to stderr
and returning an empty list.
Finally, it should print the number of QR codes found along with their decoded text content,
or a message indicating none were found.
