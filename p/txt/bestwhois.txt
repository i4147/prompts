Write a Python command-line WHOIS lookup client that queries a WHOIS API
(using the requests library) to retrieve domain registration information such as registrar,
registrant, creation/expiration dates, and nameservers.
The script should accept a domain name argument via ArgumentParser,
support optional configuration loaded from rc files
(checked at multiple standard locations like .bestwhoisrc),
and optionally handle internationalized domain names (IDN) via the idna library if available.
It should provide output formatting options including a syntax-highlighted JSON view
(via pygments with TerminalFormatter and JsonLexer)
and a human-readable indented text view generated by recursively walking nested dicts/lists,
while also including helper logic to detect and skip empty or null fields in the response.
