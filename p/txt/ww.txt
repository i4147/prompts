Write a Python script that packages the current working directory into a Python wheel file using the
external "wheel pack" command-line tool.
The script should resolve the current directory as the target,
change the working directory to its parent before running the command,
and output the resulting wheel file to "/sdcard/whl".
It should invoke the subprocess without raising an exception on failure (using check=False),
so any errors from the packing process are silently ignored rather than propagated.
