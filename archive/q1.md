# assume we are in a site-packages dir
write a python script  to repack all pkgs
by correct tag(py3-none-any or platform-based tag)
-use record file in dist-info or egg-info dir to collect every pkgs files
-ignore any missing files like .py files
- save every pkgs files under a dir in ~/tmp/repack
- save produced .whl files in ~/tmp/whl
-don't overwrite target .whl file if exists(rename appropriately)
- use mp for speedup
-report errors to ~/tmp/repack-errors.log
-show only %completed in the output using them
-collect pkgs scripts and data files too
- run (wheel pack .) for creating .whl file in ~/tmp/<pkg-name> for creating wheel
Here is the Python script to perform the repacking.
### Script Explanation
* **Dependency**: Requires `wheel` to be installed (`pip install wheel`).
* **Execution Context**: Checks if it is running inside a `site-packages` directory (or looks like one).
* **Mechanism**:
1. Scans for `.dist-info` directories.
2. Reads the `RECORD` file to locate all installed files.
3. Reconstructs the package structure in `~/tmp/repack`, mapping external files (like scripts in `../../bin`) to the correct `<pkg>.data/scripts` directory so `wheel pack` can recognize them.
4. Runs `wheel pack` to generate the `.whl` file.
5. Handles collision by renaming (e.g., appending `_1`, `_2`).
* **Concurrency**: Uses `multiprocessing.Pool` to process packages in parallel.
* **Logging**: Errors are silenced from the console and written to `~/tmp/repack-errors.log`.
* **Output**: Displays a dynamic percentage progress bar.
