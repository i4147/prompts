Write a Python script that acts as a command-line tool for stripping debugging
and symbol information from compiled shared libraries packaged inside Python
wheel files.
The tool should accept one or more wheel file paths as arguments, and when no
arguments are given, it should automatically discover all wheel files in the
current working directory.
For each wheel, the tool should unpack its contents into a temporary workspace,
locate every shared object file (files with a `.so` extension, including
versioned variants such as `.so.1` or `.so.1.2`), and run the system `strip`
utility on each one to reduce its size.
After processing, the tool should repackage the modified contents into a valid
wheel archive, overwriting the original file in place, with all directory
structure and relative paths preserved.
Display a progress indicator in the terminal while processing multiple wheels,
showing the current file being handled, a completion bar, and a percentage
counter, using a clean and readable console presentation.
Show the output of the stripping commands as they run so the user can see what
is happening.
Handle errors gracefully: if a wheel cannot be read or is not a valid archive,
report the problem clearly for that file and continue with the remaining files
rather than aborting the whole run.
Use the process exit code to indicate overall success or failure.
Include a concise help message describing usage, and make sure the tool works on
Linux and macOS systems where the `strip` command is available.
The script should be self-contained, robust, and produce a summary at the end
listing how many wheels were processed successfully and how many failed. ---
