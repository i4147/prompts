Write a Python script that compares the compiled bytecode of two Python source
files and reports the differences in a human-readable form.
The tool should accept two file paths (and handle file encoding robustly), first
check whether the two sources are structurally identical at the syntax-tree
level and, if they are, report no difference.
When the syntax trees differ, it should compile both sources, convert each
compiled code object into a readable, recursive listing of its instructions and
nested code objects, and produce a unified diff of those listings so the user
can see exactly where the generated bytecode changes.
The tool should also expose its core functionality as reusable functions that
accept raw source strings as well as file paths, use descriptive filenames in
the diff headers, and return the diff as text.
Keep the output deterministic and easy to scan, and include clear handling for
files that cannot be read or fail to compile. ---
