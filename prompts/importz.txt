Write a Python script that scans a directory tree and reports which third-party
or standard-library modules are imported by the Python source files found within
it.
The tool should accept a root directory path from the command line (defaulting
to the current working directory if none is given) and recursively locate Python
files, including files with a `.py` extension as well as extensionless
executable scripts whose first line indicates they are Python (for example, a
shebang line mentioning "python").
For each file that can be parsed, it should identify all top-level module names
referenced through absolute import statements, ignoring relative imports, and
should gracefully skip files that cannot be decoded or contain syntax errors
without stopping the overall scan.
The script should aggregate these findings and produce a clear, human-readable
summary listing the unique imported modules, ideally sorted alphabetically, and
optionally indicating which files use each module.
It should handle file-access errors robustly, avoid crashing on unreadable
paths, and exit with a meaningful status code and message when the provided path
is invalid.
Keep the output concise, well organized, and suitable for use in both
interactive terminals and automated pipelines. ---
