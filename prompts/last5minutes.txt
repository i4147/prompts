Write a Python script that takes an audio file path as a command-line argument,
extracts the final portion of that audio (approximately the last 230 seconds,
clamped so it never starts before the beginning of the file), and saves the
result as a high-quality MP3 file named last_5_minutes.mp3 in the current
working directory.
The script should display brief progress messages in the console while loading
the file, reporting the total duration of the original audio in minutes, and
confirming when the export is complete.
It should output the trimmed audio at a high bitrate (320 kbps) and a standard
CD-quality sample rate (44.1 kHz).
Handle the input as a single file path supplied at runtime, and ensure the
script runs only when executed directly rather than when imported as a module.
