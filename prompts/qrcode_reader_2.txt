Write a Python script that reads an image file from a path supplied on the
command line and detects every QR code contained in that image.
The script should report how many QR codes were found and, for each one, display
its decoded text content, its barcode/code type, and its bounding position
within the image (left, top, width, height).
If no QR code is present, it should clearly inform the user.
If the file does not exist, it should print a clear error message and exit with
a non-zero status.
Any other processing error should be reported to the user in a readable way
without crashing.
The script should also return or collect the decoded text of all detected codes
so it can be reused by other code.
Decoded content should be treated as UTF-8 text.
Keep the output human-readable and suitable for a terminal. ---
