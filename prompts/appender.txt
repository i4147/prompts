Write a Python script that reads the full contents of a text file named
"prompt.txt" located in the user's home directory, then appends that content to
the end of every existing .txt file in the current working directory.
The script should process each matching file independently, preserving each
file's original content and adding the prompt text after it, with all reading
and writing done using UTF-8 encoding.
For each file, it should report success with a clear status message showing the
file name, or report a failure message including the file name and the reason,
so that an error in one file does not stop processing of the remaining files.
The script should only run its main behavior when executed directly rather than
when imported as a module. ---
