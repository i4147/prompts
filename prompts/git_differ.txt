Write a Python script that analyzes the most recent changes in a local Git
repository and produces a structured summary report of what changed between the
last two commits.
The tool should accept a path to a repository as its main input (defaulting to
the current directory if none is given) and validate that the repository
contains at least two commits before proceeding, reporting a clear error if it
does not.
For the comparison, the script should identify the two most recent commits and
gather metadata for each one, including the commit identifier, author name,
author email, commit date, and subject line.
It should then compute file-level change statistics between the older and newer
commits, such as which files were added, modified, deleted, or renamed, along
with the number of lines inserted and removed per file and in total.
Where useful, it should also summarize the kinds of files affected (for example
by extension or directory) to give a quick overview of the change's scope.
The output should be a machine-readable JSON document written to standard
output, containing the commit metadata for both commits, the aggregate and
per-file statistics, and a concise overall summary.
The script should handle Git errors gracefully, surface failure messages in a
readable way, and exit with a non-zero status code on failure while exiting
cleanly on success.
Keep the design simple, robust, and easy to extend, and ensure the output is
stable and well-structured so it can be consumed by other tools or scripts in a
CI pipeline. ---
